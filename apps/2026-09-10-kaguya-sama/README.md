# スマスロ「かぐや様は告らせたい」設定判別ツール

SANKYO「パチスロ かぐや様は告らせたい」（スマスロ、2024/09/02導入）の設定判別ファンメイド計算機です。DMMぱちタウンの機種ページ [「パチスロ かぐや様は告らせたい（スマスロ）設定判別・天井・ゾーン・解析・打ち方・ヤメ時」](https://p-town.dmm.com/machines/4618#anc-point)（2026/09/10更新）を主データソースとし、一撃 [「かぐや様は告らせたい（スロット/スマスロ）設定差・設定判別要素まとめ」](https://1geki.jp/slot/l_kaguya/0/)（2026/02/19更新）で内容をクロスチェックして作成しました。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-kaguya-sama/

## 機能

- 数値データ入力（空欄は「データなし」として扱われ、計算に影響しません）
  - **初当り確率**：総G数とボーナス初当り回数（BIG＋スーパーBIG＋REG合算）から、二項対数尤度で設定ごとの当てはまりを算出
  - **エンディングのエピソード内訳**：エンディング到達回数のうち「かぐや」エピソード／「白銀」エピソードの回数から、偶数設定・奇数設定の傾向を算出
- 判別要素チップ（タップしてカウント）
  - ボーナス終了画面（フレーム系）：赤枠／紫枠／銀枠／金枠
  - ボーナス終了画面（キャラクター系）：デフォルメ（藤原・白銀・かぐや・石上）
  - REG中のキャラ紹介：白銀圭／早坂愛／白銀パパ／オール虹背景
  - ミニ藤原の衣装チェンジ：ラブ探偵→制服／体操着→ラブ探偵／体操着→制服
  - 獲得枚数表示：246枚over／456枚over／666枚over
  - 「濃厚」系は該当設定に候補をハード絞り込み、「示唆」系（斜体）はあくまで参考重みとして加点するのみ
- softmax正規化による設定1〜6の期待度バー表示、矛盾検出、候補設定の一覧表示

## 1geki.jpとのクロスチェックについて

- ボーナス終了画面の赤枠／紫枠／銀枠／金枠、REG中のキャラ紹介（白銀圭・早坂愛・白銀パパ・オール虹背景）、ミニ藤原の衣装チェンジ、獲得枚数表示の示唆内容は両サイトで一致することを確認しました。
- **246枚over の対象設定**はDMMの表記だけを読むと「設定2以上濃厚」に見えますが、DMMの詳細出現率表（設定2・4・6でのみ数値があり設定3・5は「－」）と一撃側の表記「偶数設定!?」を突き合わせた結果、実際は**偶数設定（2・4・6）限定**と判断し、そちらを採用しました。
- ボーナス初当り確率の設定差テーブルは一撃のみに掲載されていたため、そちらを採用しています（DMM側は「初当り確率のほか、BIG比率・特化ゾーン突入率・ロングフリーズ確率・CZスルー回数天井振り分けにも設定差がある」という記述のみで具体的な数値表はありませんでした）。

## データについて（発見したが未実装の項目とその理由）

- **ボーナス終了画面 赤枠の出現率テーブル**：設定1が約1%、設定2〜6が約2%という数値表がDMMにありましたが、差が非常に小さく、かつ紫枠／銀枠／金枠のハード濃厚チップと内容が重複するため、赤枠は「高設定示唆」の軽い示唆チップとしてのみ実装し、独立した数値チャンネルにはしませんでした。
- **特定枚数表示（246/456/666）のゲーム数帯別出現率テーブル**：DMMに1000Gごとの詳細出現率表がありましたが、総ゲーム数を区間分割する必要があり細分化しすぎるため、シンプルな「出現有無をカウントする」チップ形式に簡略化しました。
- **REG中のキャラ紹介シナリオ振り分け表**（生徒会A/B・白銀圭・白銀パパ・早坂・虹背景・大仏orベツィーの設定別選択率）：グループ化された数値ではあるものの、各キャラの「◯以上濃厚」「示唆」という定性的な記述と実質同じ結論を含むため、この表は判別要素チップの裏付けとして参照するにとどめ、独立した数値チャンネルとしては実装していません。
- **白銀＆かぐや／藤原＆かぐや／劇画調のボーナス終了画面**：「1G連or引き戻し濃厚」「引き戻し期待度◯%」など、設定ではなくAT・ボーナス性能側の示唆のみで、設定差の記載がない、または「否定条件」を伴う複雑な条件（白銀＆かぐや画面が出ずに否定された場合のみ設定4以上濃厚、など）だったため、設定判別チップとしては未実装としました。
- **初当り時のBIG比率／スーパーBIG比率／エクストラBIG比率／特化ゾーン当選率／ロングフリーズ確率**：DMMの「設定推測要素まとめ」に「高設定ほど高い!?」との記載はありますが、具体的な設定別数値表が見つからなかったため、純粋な推測にとどまり実装を見送りました。
- **エクストラボーナス昇格率**：DMMに数値がありましたが「設定1」のみの掲載で、設定2〜6の比較データがなく不完全なため未実装です。

## 技術メモ

本ツールは `apps/2026-09-06-tokyo-ghoul-slot-checker/` のCSS・HTML骨格・JSアーキテクチャ（`logBinomLikelihood` による二項対数尤度、`computeCandidateSettings` によるハード除外、`buildChips` によるチップ生成、softmax正規化による `render`）をそのまま踏襲しています。空欄の数値フィールドを「データなし」として安全に扱うため、`apps/2026-09-07-monhun-rise/` の `parseField`（空文字列を `null` として返し、各チャンネルは自分自身の入力が `null` でない場合のみ尤度計算に加える）パターンを採用しました。
