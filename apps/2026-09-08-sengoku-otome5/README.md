# L戦国乙女5「業火を穿つ宿焔の双刃」設定判別ツール

「L戦国乙女5 業火を穿つ宿焔の双刃」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/5009#anc-point)（設定判別・推測ポイント自体の最終更新: 2026/08/03、ページ全体の最終更新日は2026/09/09だが該当箇所以降の更新は無関係な解析情報の追記）に掲載されている判別要素をそのままの分類（終了画面系→エンディング→獲得枚数表示）で反映し、実戦データと示唆演出の出現回数から設定期待度を算出する。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-08-sengoku-otome5/

## 機能

- **数値データ**（①）: 以下2系統をそれぞれ独立した二項尤度チャンネルとして入力可能
  - 総G数ベースの当選率（戦国乙女ボーナス確率・AT初当り確率）— 総G数は共有、戦国乙女ボーナス確率はDMM掲載、AT初当り確率は一撃調べ（DMM側には同テーブルの掲載なし）
  - 巫女ポイント0pt到達時の乙女アタック（CZ）当選率（カンスケ以外のモード）— DMM・一撃の両方に完全一致するテーブルが掲載
- **判別要素**（②）: 出陣ボーナス終了画面（可/吉/良/優/極スタンプ）・AT終了画面（乙女集合B）・獲得枚数表示（222〜666枚OVER）・エンディングのゴエモンボイス（奇数/偶数示唆、高設定示唆［弱/強］、濃厚系5種、否定系2種）の計19要素を、DMMの分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 金文字表示の「〜濃厚」「〜否定」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と［弱/強］の強さに応じて参考程度の重みだけを加える
- タップ式のカウンターUI（コンパクトな一覧チップ表示でページを短く保つ）
- 数値データとカウント結果を組み合わせて、現在の有力候補と最有力設定をリアルタイム表示
- 広告枠（`.ad-slot`）を3か所設置：ヘッダー直下（728×90）、判別要素と結果の間（300×250）、フッター上（728×90）。今はプレースホルダー表示のみ（詳細はリポジトリルートのREADME「広告の設置について」を参照）

## 一撃（1geki.jp）とのクロスチェック

[一撃「戦国乙女5」設定差・設定判別](https://1geki.jp/slot/l_otome5/0/)（2026/08/03更新）を確認したところ、戦国乙女ボーナス出現率・乙女アタック突入期待度（カンスケ除く）・ボーナス終了画面のスタンプ示唆・獲得枚数表記による示唆・エンディング中のゴエモンボイスは、いずれもDMMぱちタウンの内容と完全に一致していた。一撃側にのみ掲載されていた**AT初当たり確率**（設定1: 1/359.5〜設定6: 1/262.9）は、DMMには存在しない独立した数値テーブルだったため新たに数値チャンネルとして採用した。

## データについて

以下は両サイトを確認したが、理由があって採用しなかった項目：

- **乙女ストラップモードの設定差**（ノブナガ・ゴエモン・ヒデヨシ）: DMM「高設定ほど出現しやすい!?」、一撃「乙女ストラップモードの設定差」も同様に、いずれも具体的な設定別の数値テーブルを伴わない定性的な記述にとどまっており、判別要素として数値化できないため未採用とした。
- **AT終了画面の残り6演出**（ノブナガ／マサムネ＆ヒデヨシ／モトナリ＆ドウセツ＆ソウリン／敵集合／イエヤス＆シンゲン＆カンスケ＆ヨシモト／乙女集合A）: いずれも「テーブルB以上のチャンス」「天国テーブル濃厚」など主に通常時の周期テーブル（A/B/天国）を示唆する演出で、設定そのものを示すのは「テーブルが否定された場合のみ設定◯以上濃厚」という条件付きロジックのため、単純なタップ式カウンターの枠組みに合わず未採用とした。単純に「出現＝設定◯以上濃厚」となる乙女集合B（金）のみを採用している。
- **ハルルナPUSH**（一撃、「設定4以上濃厚!?」）: 実戦上1件確認したのみの「推察」情報であり、確定的な濃厚パターンとして裏付けられていないため未採用とした。
- **隠れ凪**（一撃、文字色ごとの設定示唆）: 「示唆内容は、他機種を参考にした推察」「現状未確認ではある」と明記されており、本機での実証データがなく、かつ専用アプリ（打-WIN LITE）利用時のみ出現する要素のため未採用とした。
- **強カワチャンス当選率・周期到達G数・当選周期**（一撃、ショールーム実戦データ）: いずれも設定4・5・6のみのサンプル調査（自社調査）で設定1〜3のデータが存在せず、6段階の尤度計算に使えないため未採用とした。
- **本能寺の変（AT中CZ）移行確率・成功期待度、決戦ノ刻成功期待度、出陣ボーナス確率、繚乱の刻「紫炎」のAT期待度、周期ごとのAT当選期待度**（一撃）: いずれも設定1の数値のみ判明しており、設定2〜6が「???」で欠落しているため、6段階の尤度計算に使えず未採用とした。

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算: 各数値チャンネルの二項分布 `P(k|n,p)` の対数尤度を合算し、示唆要素は出現回数（上限3回でキャップ）×tier別の重み（弱0.2／通常0.35／強0.5）を加算。その後ソフトマックス的に正規化（一様事前分布を仮定）
- 実装パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲：`numericInputs`配列（id列挙順）→イベントリスナー（`numericInputs.forEach((el) => el.addEventListener('input', render))`）→`render()`内の分割代入、の3点の並び順を完全一致させて配線漏れを防止
- 判別要素は単一のデータ配列（`ITEMS`）で定義し、各項目の`kind`（hard/soft）と`cat`フィールドで確定/示唆の別とDMMの分類ラベルを保持。チップUIは`cat`が変わるタイミングで自動的にラベル＋新しい行を生成する
- 「戦国乙女ボーナス確率」と「AT初当り確率」は同じ「総G数」を母数とする独立した二項分布のため、`totalG`の入力欄は1つだけ用意し、それぞれの当選回数を別欄で入力する形にした（東京喰種ツールの下段リプレイ・AT直撃グループと同じパターン）
