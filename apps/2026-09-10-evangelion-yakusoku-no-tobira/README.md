# スマスロ「LBヱヴァンゲリヲン ～約束の扉～」設定判別ツール

スマスロ「LBパチスロ ヱヴァンゲリヲン ～約束の扉～」（ビスティ、2025年7月7日導入）の設定判別ツールです。DMMぱちタウンの[「LBパチスロ ヱヴァンゲリヲン ～約束の扉～」設定判別・推測ポイント](https://p-town.dmm.com/machines/4830#anc-point)（2026/09/10更新）で公開されている、設定1〜6が完全な数値のみを使って各設定の対数尤度を計算し、softmaxで正規化して期待度を表示します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-evangelion-yakusoku-no-tobira/

## 機能

- ボーナス種別出現率（赤7/青7スーパーBIG・黄7BIG・REG・暴走モード、総G数ベース）を入力すると二項対数尤度で各設定の期待度を算出
- ベル・弱スイカ・強スイカ・チェリーそれぞれの「ボーナス同時当選率」を独立チャンネルとして入力可能
- カヲル（ボーナス終了画面／REG中キャラ紹介）＝設定6濃厚、BT中赤7スーパーBIGビタ押しムービー（ミサト＆リツコ→高設定示唆[弱]／リリス→高設定示唆[強]／ゲンドウ→4以上濃厚／加持→5以上濃厚／カヲル→6濃厚）などの示唆演出をタップ式チップでカウント
- ハズレ単独当選→暴走モード、ベル同時当選→黄7BIGは「設定2以上濃厚」のハード除外要素として実装
- チェリー同時当選時の赤7/青7スーパーBIGの偶奇差、弱スイカ同時当選での赤7優遇、リプレイ・ハズレ単独同時当選でのREG優遇を「示唆[弱]」として反映
- 空欄のフィールドは「未入力（データなし）」として扱われ、0を観測したものとして計算に混入しない（`parseField`によるnull安全設計）

### 1geki.jpとのクロスチェック

- ボーナス確率（赤7/青7SBB・黄BB・REG・暴走モード合算）は両サイトで完全一致（1〜6すべて掲載）。
- 同時当選期待度（ハズレ単独・リプレイ・ベル・弱スイカ・強スイカ・チェリー）も両サイトで一致する数値を確認。
- 1geki.jpは「単独暴走モード出現で設定2以上濃厚」「ベルから黄7BB出現で設定2以上濃厚」「弱スイカから赤7SBB出現で高設定期待度アップ」「チェリー同時当選のSBBの赤・青の比率に偶奇の差」「リプレイ+REG出現で高設定期待度アップ」と、DMM側の「役ごとの当選ボーナスの特徴」表の記述内容と一致することを確認済み。
- BT中赤7スーパーBIGビタ押しムービーの示唆段階（デフォルト→高設定示唆[弱]→高設定示唆[強]→4以上濃厚→5以上濃厚→6濃厚）も両サイトで同一の分類。

## データについて（見つけたが採用しなかったもの）

以下は調査時に見つけたが、**設定1〜6の一部しか公開されていない、または比較不能な単一設定のみの実測値**だったため、フィクション性の混入（捏造）を避けるため採用していません。

- DMM「ベル・チェリー・スイカ確率（実戦値）」：設定2・設定6の2つのみ実戦値が公開されており、設定1・3・4・5のデータなし → 除外
- 1geki.jp「小役確率の比較（実戦上）」：設定1（解析値）と設定6（実戦値のみ）の比較で、設定2〜5の数値なし → 除外
- 1geki.jp「【設定6実戦データからの考察】その他の数値」（ボーナス出現率・終了画面・REGキャラ紹介の実戦カウント）：いずれも設定6のみの単発サンプル値で他設定との比較ができない → 除外
- DMM「強スイカ」「リーチ目役」契機のボーナス種別内訳：「大きな設定差はナシ」「ボーナス確定」と明記されており、設定差別の信号がないため数値チャンネル化を見送り（強スイカ・チェリーの「同時当選期待度」自体は別指標として設定差があるため採用済み）
- ペンペンの登場タイミング示唆：「出現タイミングで何かを示唆」とのみ記載され、具体的な判別パターンが未公開のためチップ化を見送り

## 技術メモ

`apps/2026-09-06-tokyo-ghoul-slot-checker/` の実装（CSS・HTML骨格・JSアーキテクチャ：`logBinomLikelihood` による二項対数尤度、`computeCandidateSettings` によるhard要素の候補絞り込み、softmax正規化、タップ式チップUI）をベースに作成しました。空欄安全設計（`parseField`によるnull判定）は `apps/2026-09-07-monhun-rise/` の実装パターンを踏襲しています。本機種は公開データが全設定（1〜6）で完全だったため、`apps/2026-09-06-valvrave-2/` のような `SETTINGS = [...]` オブジェクトキー方式（欠測設定の除外）は使用していません。
