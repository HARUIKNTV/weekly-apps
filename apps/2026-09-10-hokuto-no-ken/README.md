# スマスロ「北斗の拳」（無印）設定判別ツール

サミー「スマスロ北斗の拳」（無印、2023年4月3日導入）の設定判別ファンメイド計算機です。[DMMぱちタウンの機種ページ（機種ID: 4301）](https://p-town.dmm.com/machines/4301#anc-point)（「設定判別・推測ポイント」セクション、2026/09/08更新時点）に掲載されている数値データ・示唆演出の出現率をもとに、入力した実戦データから設定1〜6の期待度を対数尤度ベースで算出します。

## 機能

- **① 数値データ**：以下3つのチャンネルを独立した二項尤度として計算します。
  - 小役・バトルボーナス確率（総G数ベース、n共有）：BB当選回数／弱スイカ・強スイカ・中段チェリー成立回数／リーチ目役成立回数
  - 設定変更（リセット）後の内部状態移行率（天国＋本前兆の合算値）
  - BB終了後の内部状態移行率（天国＋本前兆の合算値）
  - 各欄は空欄なら「データなし」として扱われ、0を入力したときとは区別して計算から除外されます。
- **② 判別要素**：BB終了時のボイス（サブ液晶タッチ）・サミートロフィー・初代画面（激レア演出）・獲得枚数表示の出現をタップでカウント。「濃厚」は設定候補をハード確定し、「示唆」は参考程度の重みだけを加算します。
- **③ 結果**：設定1〜6のうち確度のある数値データが存在する設定1・2・4・5・6の相対期待度をバーで表示し、矛盾する濃厚が同時カウントされた場合は警告を出します。

## 設定3データが存在しないことについて

DMMぱちタウン・一撃（1geki.jp）のいずれのサイトでも、小役確率・BB確率・内部状態移行率など**すべての設定別数値表が「設定1・2・4・5・6」の5列のみで構成されており、設定3の数値は一切公開されていません**。本機は物理的には1〜6の6段階設定機ですが、確度のある数値が存在するのは5段階分のみのため、`apps/2026-09-06-valvrave-2/`が同じ理由で採用している`SETTINGS = [1, 2, 4, 5, 6]`配列パターンをそのまま踏襲し、結果画面にも設定3を表示しません（設定3の数値を独自に補間・推測することはしていません）。

## 1geki.jpとのクロスチェックについて

DMMぱちタウンと一撃（1geki.jp）の「[北斗の拳（スマスロ）設定差・設定判別要素](https://1geki.jp/slot/s_sma_hokutonoken/0/)」（2026/03/04更新）は、小役確率・BB確率・BB終了時のボイス出現率・サミートロフィー出現率・内部状態移行率のいずれも完全に一致した数値を掲載しており、両サイトの数値をそのまま採用しています。バトルボーナス合算確率（1/383.4〜1/235.1）は1geki.jp側にのみ明記されていたため、そちらを採用しました。

## データについて

以下は両サイトで見つけたものの、本ツールには採用しなかった要素です。

- **小役契機の内部状態移行率（地獄／通常／天国滞在時ごとの各レア役移行率）**：弱スイカ・角チェリー等の当選時に「現在の内部状態（地獄/通常/天国）」に応じて移行率が変わる詳細表がありますが、プレイヤーは自分が現在どの内部状態に滞在しているかを確実に把握できないため、確度の高い(n, k)データとして入力させることができず除外しました。
- **チャンス目・角チェリーの単純出現確率**：DMMぱちタウン自身が「設定差のある小役確率」として弱スイカ・強スイカ・中段チェリー・リーチ目役のみを明記しており、チャンス目・角チェリー単体（弱スイカ・強スイカ以外の成立形）には設定差の記載がなかったため対象外としました。
- **宿命バトル・共闘（レイ／トキ）・無想転生チャンス／バトルの各種演出・抽選**：BB中の演出内容や継続抽選、キャラ登場率に関する要素で、いずれもBB中の細かいゲーム数管理が必要な上、大半は設定差ではなく出玉やループ率に関わる抽選のため対象外としました。宿命バトルのトータル確率（1/162.5〜1/145.0）も同様に、BB中の消化ゲーム数を分母にする必要があり通常プレイでの入力が非現実的なため除外しました。
- **BB継続率（66/79/84/89%）の選択率**：1geki.jpに「継続率の選択率には設定差がなく（中略）天井到達時は継続率84%以上選択率が優遇される」と明記されている通り、継続率テーブル自体には設定差がなく、天井到達率を介した間接的な差でしかないため、直接のチャンネルとしては採用していません。
- **天井短縮抽選（300/777/800G到達時）**：「頻度は低いが当選＝高設定のチャンス」という定性的な言及はあるものの、設定別の具体的な当選率数値が両サイトとも非公開のため、タップ集計要素としても数値チャンネルとしても採用しませんでした。
- **実戦データ記事内の小役確率（実戦値）**：DMMぱちタウンの実戦検証記事に設定1・5・6のみの少数サンプル実戦値が掲載されていますが、少数サンプルの参考値であり公式の理論値と別物のため、本ツールでは理論値（設定判別・推測ポイント記載の数値）のみを採用しています。
