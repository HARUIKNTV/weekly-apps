# アニマルスロット ドッチ 設定判別ツール

北電子のスマスロ「アニマルスロット ドッチ」（型式名: LアニマルスロットドッチZT、2026年4月20日導入）向けの設定判別ファンツールです。DMMぱちタウン「[アニマルスロット ドッチ（スマスロ）パチスロ｜設定判別・天井・ゾーン・解析・打ち方・ヤメ時](https://p-town.dmm.com/machines/4964)」（2026/09/08更新）の「設定判別・推測ポイント」を主データとして、一撃「[アニマルスロット ドッチ 設定差・設定判別要素まとめ](https://1geki.jp/slot/l_asd/0/)」（2026/04/28更新）の数値・示唆内容と突き合わせたうえで実装しています。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-animal-slot-docchi/

## 機能

- 総G数・BIG当選回数・REG当選回数・チェリー成立回数・スイカ成立回数を入力すると、設定1〜6ごとの二項尤度を計算して現在の実戦値がどの設定に近いかを算出します（各欄は空欄なら「データなし」としてその項目の計算をスキップし、0回とは区別します）。
- 以下3カテゴリー・計28種類の示唆演出をタップ式チップでカウントできます。
  - **REG中のキャラ紹介**（7種）: ホッキョクグマ／ネコ（高設定示唆）、ペンギン／ウサギ（否定）、ライオン／ブルドッグ／ジャグラー（濃厚）
  - **ジャングルボーナス終了画面のチップ配置**（13種）: 2桁奇数・偶数マスの示唆、赤黒マスの示唆、1・4・7／2・4・7（否定）、2・4・6／2・5・6／4・5・6／5・6／6（濃厚）
  - **ST終了画面のキャラカード**（8種）: 赤チップのみ（高設定示唆）、リラックスシロクマ〜レジェンド舞妓の否定・濃厚カード（一撃のNo.表記も併記）
- 「濃厚」「否定」（金文字＝hard要素）は候補設定を確定・除外し、「示唆」（斜体＝soft要素、弱/通常/強の重み付け）はあくまで参考程度に期待度を加算するだけで、候補を除外しません。

## 1geki.jp とのクロスチェックについて

両サイトの数値・示唆内容はすべて一致することを確認しました。

- ボーナス確率（BB/RB、設定1〜6）・チェリー/スイカ確率（設定1〜6）は数値まで完全一致。
- REG中のキャラ紹介は、キャラ名と示唆内容（濃厚/否定/高設定示唆の強弱）が両サイトで一致。
- ジャングルボーナス終了画面のチップ配置は、パターン表記（p-town: 「1・4・7」／1geki: 「1･7･4（1なし）」など）と示唆内容が一致。
- ST終了画面は、p-town がキャラ名（例: 巫女ウサギ）、1geki がカード番号（例: No.456）で表記しているだけで、示唆内容（設定4以上濃厚など）は完全に一致。ツールのラベルには両方を併記しました。

## データについて

見つかったが今回のツールには採用しなかったデータと、その理由は以下の通りです。

- **赤満月移行状態レベル示唆**（モノクロウィンドウのシロクマセリフ）: これは内部の「赤満月移行状態レベル」（1〜6段階で管理される演出モード用の内部パラメータ）を示唆するものであり、機種の隠しパラメータである「設定」（1〜6）そのものを示唆する要素ではないため採用しませんでした。両者を混同すると誤った設定判別になります。
- **高確・超高確移行率**、**BIG中／ジャングルボーナス中のポイント獲得抽選**、**継続ジャッジの上乗せ当選率**: 公開されている数値はいずれも設定差のない固定値（全設定共通）であり、設定判別には使えないため除外しました。
- **ST中のミッション/DOTCH確率**（約1/70、約1/90）、**ST中のリーチ目確率**（約1/55）: 設定別の内訳が公開されておらず、単一の概算値のみのため除外しました。
- **天候演出・デカマジロ演出・デカキリン演出・監視カメラ演出等の通常時演出**: いずれも「成立役」や「ボーナス期待度」を示唆する演出であり、設定差そのものを示唆するものではないため対象外としました。

なお、今回採用したすべての数値・示唆要素は設定1〜6の全設定でデータが揃っており、一部設定のみ欠落しているような項目はありませんでした。そのため `apps/2026-09-06-valvrave-2/index.html` にあるような設定を部分的に除外する `SETTINGS` 配列パターンは使用していません。

## 技術メモ

`apps/2026-09-06-tokyo-ghoul-slot-checker/` の実装をベースにしています。

- CSS（白・黒・赤基調のパレット）、HTML骨格（ヘッダー／広告枠／①数値データ・②判別要素・③結果のカード構成／出典／免責事項／フッター）、フィードバックウィジェット（`.fb-fab` の💬ボタン、FormSubmit.co 経由でのメール送信）は上記実装から流用しています。
- 判別ロジックは各示唆演出を「hard（濃厚/否定＝候補の確定・除外）」と「soft（示唆＝重み付けのみ）」に分類し、独立した二項対数尤度（`logBinomLikelihood`）をチャンネルごとに積算してsoftmax正規化する方式です。
- 数値入力欄は `parseField()` により空欄を `null`（データなし）として明示的に区別し、0件確定と混同しないようにしています（`apps/2026-09-07-monhun-rise/index.html` のパターンを踏襲）。
