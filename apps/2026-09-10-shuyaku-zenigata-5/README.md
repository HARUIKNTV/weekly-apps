# L主役は銭形5 設定判別ツール

「Lパチスロ 主役は銭形5（スマスロ）」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4877#anc-point)（2026/08/28更新）に掲載されている判別要素をそのままの分類（ボーナス終了画面のスタンプ／小役確率）で反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。オリンピア製スマスロで、導入開始日は2025年10月06日。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-shuyaku-zenigata-5/

## この機種の特徴：設定1のデータが存在しない

DMMぱちタウン・一撃(1geki.jp)ともに、ボーナス初当り確率・通常時デカ目確率の表が設定2〜6の5列のみで構成されており、設定1の数値は両サイトとも一切公開されていない（「調査中」等の注記すらなく、テーブル自体に設定1の列が存在しない）。設定1の値を補間・推測で埋めることはせず、本ツールも`SETTINGS = [2, 3, 4, 5, 6]`という設定空間で計算しており、結果表示にも設定1は出てこない。

## 機能

- **数値データ**（①）: ボーナス初当り確率、通常時デカ目確率（本前兆中以外）をそれぞれ独立した二項尤度チャンネルとして入力可能。両チャンネルとも母数（総G数）は共通のため、総G数の入力欄は1つにまとめた
- **判別要素**（②）: ボーナス終了画面のスタンプ（吉・良・優・極）、獲得枚数表示（333/444/555/666枚OVER）を、DMM・一撃で共通して明記されている「設定◯以上濃厚」「設定◯濃厚」の金文字要素としてタップ式カウンターで記録
  - 金文字表示の「〜濃厚」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 本機種は「示唆」止まりの要素（確定情報ではないもの）を裏付けとなる設定別データ付きで見つけられなかったため、②はすべてhard（濃厚）要素のみ
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用
- 空欄の数値項目は「データなし」として扱い、0回観測と混同しない（`parseField`によるblank-safety）

## 一撃（1geki.jp）とのクロスチェック（2026-09-10）

[一撃「主役は銭形5」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_zenigata5/0/)（2026/03/12更新）を確認したところ、以下が判明した。

- **ボーナス初当り確率**（設定2: 1/424.5〜設定6: 1/300.5）は一撃のみに掲載されており、DMM本文では数値表が見当たらなかった（DMM上は「ボーナス出現率」がグラフ画像のみでテキスト化できず）ため、①の新規チャンネルとして一撃データを採用した
- **通常時デカ目確率**（本前兆中以外、設定2: 1/21580.7〜設定6: 1/5561.8）はDMM・一撃の数値が完全に一致しており、①に採用
- **獲得枚数表示の閾値**（333/1333枚OVER→設定3以上濃厚、444/1444枚OVER→設定4以上濃厚、555/1555枚OVER→設定5以上濃厚、666/1666枚OVER→設定6濃厚）は一撃に明記されていたため②に追加。DMM側にはこの表自体は見当たらなかったが、内容はDMMのボーナス終了画面スタンプと同じ閾値構成（3/4/5/6段階）で矛盾はない
- **ボーナス終了画面のスタンプ**（吉・良・優・極）はDMM・一撃とも同一内容で確認でき、②に採用。一撃側にのみ記載のあった「銭形（手錠）」「銭形（十手）」の2枚は示唆内容が「???」（不明）と明記されており未採用とした

## データについて

- **ST（デカタイム）終了画面のモード示唆**（次元＝通常B示唆［弱］、五ェ門＝通常B示唆［中］、ルパン＝通常BorC示唆［中］、銭形＆ルパン＝通常B以上濃厚、不二子＝通常C以上濃厚）: DMMに詳細な記載があるが、これらはいずれも内部モード（通常A/B/C/天国）の示唆であり、設定そのものを示唆するものではない。「高設定ほど良いモードが選ばれやすい」という定性的な相関は存在するものの、モードごとの設定別選択率を示す具体的な数値テーブルは公開されていないため、モードから設定を逆算する根拠がなく未採用とした
- **ステージチェンジ演出のモード示唆**（銭形＝通常B以上濃厚、不二子＝通常C以上濃厚）も同様の理由（モード示唆であり設定示唆ではない）で未採用
- **ボーナス出現率グラフ**: DMMのトップに掲載されているが画像（グラフ）のみでテキスト化された数値表がなく、正確な数値を抽出できないため未採用（代わりに一撃に掲載の同種数値「ボーナス初当り確率」を採用）
- **BIGジャッジ成功期待度・超デカタイム性能などの数値**: DMMに複数の期待度が載っているが、いずれも「（設定2）」の単一設定における参考値のみで、設定間の比較テーブルではないため設定判別には使えず未採用
- **セブンジャッジ／ラストジャッジの演出パターン別期待度**: 次元・五ェ門・ルパン・不二子など複数キャラ×複数パターンの期待度表が多数あるが、いずれも「対応レア役かどうか」「継続G数」に依存する演出成功率であり、設定差の記載が一切ないため未採用
- **銭形（手錠）／銭形（十手）の終了画面**: 一撃に画像は掲載されているが示唆内容が「???」（不明）と明記されているため未採用

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 設定空間を`SETTINGS`配列で保持し、確率テーブルもオブジェクト（`{2: ..., 3: ..., ...}`）で持たせることで、設定1のデータが存在しない5段階設定の機種にも対応できる形に一般化した（[革命機ヴァルヴレイヴ2](../2026-09-06-valvrave-2/)と同じパターン）
- 数値入力の空欄安全性（`parseField`によるnull判定と、チャンネルごとの個別ゲーティング）は[モンハンライズ](../2026-09-07-monhun-rise/)を参照実装として踏襲
- チップUI・尤度計算・フィードバックウィジェットの基本パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲
