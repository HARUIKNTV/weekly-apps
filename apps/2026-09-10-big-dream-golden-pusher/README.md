# スマスロ「ビッグドリーム THE GOLDEN PUSHER」設定判別ツール

サミー「スマスロ ビッグドリーム THE GOLDEN PUSHER」（2026年5月11日導入）の設定判別ツールです。
[DMMぱちタウン「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4981#anc-point)（2026/09/10更新）の数値データ・示唆演出データをもとに、AT初当たり確率・CZ出現率・天井選択率などの数値入力と、AT終了画面／サミートロフィー／獲得枚数表示／エンディングボイスなどの示唆演出の出現回数（タップカウンター）を組み合わせて、設定1〜6の期待度を対数尤度＋softmaxで算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-big-dream-golden-pusher/

## 機能

- **① 数値データ**：わかる範囲で入力するほど精度が上がる4つの独立した二項分布チャンネル
  - AT初当たり・CZ（ジャッジメント）出現率（総G数ベース、AT当選・CZ当選をそれぞれ独立集計）
  - ステーションチェンジ時の初期ボール5個獲得率
  - 通常AT終了後の天井選択率（999G以下）
  - 上位AT終了後の天井選択率（555G以下）
  - 各欄は空欄なら「未入力（データなし）」として扱われ、「0件」と誤認識しません（`parseField`で null/非負整数を明確に区別）。
- **② 判別要素**：出現演出をタップでカウントする4カテゴリー・25演出
  - AT/上位AT終了画面（金銀財宝の山・立ち絵・見返り・玉座・覚醒ギルガメッシュ＝濃厚、銃＆玉・剣＝示唆）
  - 獲得枚数表示（456枚/4560枚＝4以上濃厚、666枚/6666枚＝6濃厚）
  - サミートロフィー（銅〜虹＝設定2以上〜6濃厚）
  - エンディング中のレア役ボイス（奇数/偶数示唆の弱〜強タイヤ＋濃厚系4種）
- **③ 結果**：対数尤度を合算し、濃厚要素でハード除外した候補内でsoftmax正規化した設定期待度バーを表示。

[一撃「ビッグドリーム」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_bigdream/0/)（2026/06/02更新）と突き合わせ、以下の数値が両サイトで完全一致することを確認しました。

- ステーションチェンジ時の初期ボール5個振り分け：3.1%, 3.5%, 3.9%, 4.7%, 5.9%, 6.3%
- 天井ゲーム数の999G以下／555G以下・合算選択率（AT後／設定変更時・上位AT後の2系統）
- AT終了画面（銃＆玉・剣・財宝の山・立ち絵・見返り・玉座・覚醒）の出現比率
- 獲得枚数表示・エンディング中のレア役ボイスの示唆内容と出現比率
- サミートロフィーの示唆内容（DMM側に詳細出現率表あり、1geki側は示唆内容のみ）

AT初当たり確率（1/629.3〜1/536.2）はDMM側に単独の一覧表がなく、1geki.jp側のみに掲載されている数値のためそちらを採用しました（DMM本文中でも「概ね1/550前後が設定4以上の基準」と同水準の記述があり整合的です）。

## データについて

本機種は2026年5月11日に導入済みで、DMMぱちタウンの「設定判別・推測ポイント」は2026/09/10時点で「準備中」ではなく実データが公開されているため、実装対象として適格と判断しました。

以下は発見したが本ツールには組み込まなかったデータです（すべて設定差・確定情報が無い、または本ツールの目的（設定判別）に直接寄与しないため）：

- **小役確率**（弱チャンス目合算1/83.9・中チャンス目合算1/179.6・強チャンス目合算1/1489.5・順押し白7揃い1/16384.0）：設定差の記載がなく、全設定共通の確率として掲載されているため除外。
- **CZ＆AT終了後のPUSHボイス（ギルガメッシュボイス／ELENAボイス）**：ボール天井の残り個数を示唆する演出で、設定差の示唆ではないため除外。
- **アイキャッチの天井ゲーム数示唆（通常／赤／キリン柄）**：次回の天井ゲーム数を示唆する演出で、設定への直接的な示唆ではないため除外。
- **1stジャッジの成功期待度（×の個数別）**：CZ内部抽選の成功期待度で、設定差の記載がないため除外。
- **ボール天井の最大値・ロングフリーズの発生契機**：DMMぱちタウン上で「調査中」と明記されており、未確定データのため除外。
- **ステーションチェンジ時の初期ボール個数の完全な4区分（2個/3個/4個個数振り分け）**：DMM・1geki.jpとも表中で「ー」（非表示・0%相当）を含む形式で提供されており、テキスト抽出時に列の対応が不明瞭な箇所があったため、両サイトで数値が完全一致し信頼できる「5個」の列のみを二項分布チャンネルとして採用し、残りの区分は組み込みませんでした。

※本機種は設定1〜6のすべてで実測データが公開されており、一部設定のみ欠落しているデータは見つかりませんでした（`SETTINGS`除外パターンの適用は不要でした）。
