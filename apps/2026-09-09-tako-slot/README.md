# スマスロ「タコスロ」設定判別ツール

4号機の名機『タコスロ』がボーナストリガー（BT）機として復活したユニバーサルブロス「スマスロ タコスロ」（2026年9月7日導入）向けの設定判別ファンツールです。[DMMぱちタウン「スマスロ タコスロ」設定判別・推測ポイント](https://p-town.dmm.com/machines/5049#anc-point)（2026/09/09更新）に掲載されている情報をもとに、判別要素（演出）の出現回数から設定期待度の目安を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-09-tako-slot/

## 機能

- BIG終了画面の「レアパターン（夜）」出現をタップしてカウント（高設定示唆）
- 「レアパターン（夜）出現時にタコゲームが一度も入賞しなかった」場合をタップしてカウント（設定2以上濃厚のハード判別要素）
- 濃厚/否定要素から矛盾する設定を自動的に除外し、残った候補の中で対数尤度（示唆の重み付け）をもとにソフトマックスで設定1〜6の期待度バーを表示

## 1geki.jp とのクロスチェックについて

[一撃「タコスロ（スマスロ）」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_taco/0/)（2026/09/04更新）にも同一機種のページが存在し、確認できました。掲載されている数値（ボーナス確率・小役確率・同時当選期待度）およびBIG終了画面の解説はDMMぱちタウンの内容とほぼ一致しており、独自に矛盾する追加情報は見つかりませんでした。また、一撃の実戦データページ（[設定5＆6実戦データ](https://1geki.jp/slot/l_taco/7/)）でも「タコゲーム未入賞×レアパターンで設定2以上濃厚」の記述が裏付けとして確認できています。

## データについて

本機は2026年9月7日導入の新台で、調査時点（2026年9月9日）でもまだ導入から2日しか経っておらず、公開されている設定差データはかなり限定的です。

**掲載されているが今回は使用しなかったデータ（理由：設定1〜6のうち3・4が非公表で「完全な1〜6テーブル」の要件を満たさないため）:**

- ボーナス確率（BB・RB・合算）: 設定1・2・5・6のみ判明。合算1/168.9〜1/149.6。設定3・4は非公表。
- 通常時の小役確率（リプレイ・プラム・スイカA/B・スイカ合算・チェリーA/B/C・チェリー合算）: いずれも設定1・2・5・6のみ判明。設定3・4は非公表。
- ボーナス同時当選期待度（プラム・チェリーAB合算）: 設定1・2・5・6のみ判明。差も非常に小さい（プラム0.72%〜0.83%、チェリー2.87%〜3.14%）。設定3・4は非公表。
- DMMぱちタウン特集記事の「設定1・6実戦値」（通常ゲーム数、BIG/REG回数など）: 個別ショールームの実戦データであり、公式な設定差テーブルではないため使用せず。
- 「タコBIGと白7BIGの偏重」の考察: 記事内で「詳細はまだ判明していません」と明記された純粋な推測のため除外。

これらはいずれも将来的に設定3・4のデータが判明すれば、他ツールと同じ二項対数尤度チャンネルとして追加できる設計にしてあります（`index.html` 内のコメント参照）。

**データが薄いことについての明記:** 上記の通り、現時点で使用できる確定的な判別要素は「BIG終了画面のレアパターン関連」の2件のみです。今後、稼働が進んで設定3・4の数値や新たな示唆演出が判明次第、本ツールも更新される想定です。

## 技術メモ

`apps/2026-09-06-tokyo-ghoul-slot-checker/` を参照実装とし、CSS（白/黒/赤パレット）とHTML骨格、JSアーキテクチャ（`ITEMS` 配列 + `buildChips` + `computeCandidateSettings` + `logBinomLikelihood` + ソフトマックス正規化）をそのまま踏襲しています。本機は数値チャンネルが（今のところ）存在しないため、`numericInputs` は空配列ですが、`apps/2026-09-07-monhun-rise/` の `parseField`（空欄=「データなし」として扱うヘルパー）パターンをコメントとして残し、将来データが揃った際に同じ配線で数値入力欄を追加できるようにしています。
