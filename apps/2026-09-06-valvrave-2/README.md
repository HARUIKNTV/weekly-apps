# 革命機ヴァルヴレイヴ2 設定判別ツール

「Lパチスロ 革命機ヴァルヴレイヴ2（ヴヴヴ2スマスロ）」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4885#anc-point)（2026/09/06更新）に掲載されている判別要素をそのままの分類（CZ・ボーナス終了画面／AT終了画面の背景／上乗せゲーム数／サブモニターの機体／ハラキリチャレンジ／ラウンド開始画面／マギウスマーク／獲得枚数表示）で反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-06-valvrave-2/

## この機種の特徴：設定3が存在しない

DMMぱちタウンの全テーブルが設定1・2・4・5・6の5列で構成されており、設定3は存在しない5段階設定の機種。本ツールもこれに合わせて`SETTINGS = [1, 2, 4, 5, 6]`という設定空間で計算しており、結果表示にも設定3は出てこない。

## 機能

- **数値データ**（①）: AT初当たり確率、BAR揃い時のAT直撃当選率をそれぞれ独立した二項尤度チャンネルとして入力可能
- **判別要素**（②）: CZ・ボーナス終了画面、AT終了画面の背景、上乗せゲーム数のゾロ目、サブモニターの機体、ハラキリチャレンジの夢夢ちゃんプレミアム、ラウンド開始画面、マギウスマーク、獲得枚数表示のすべての要素を、DMMぱちタウンの分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 金文字表示の「〜濃厚」「〜否定」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と強さに応じて参考程度の重みだけを加える
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用

## 一撃（1geki.jp）とのクロスチェック（2026-09-07）

[一撃「ヴァルヴレイヴ2」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_valvrave2/0/)（2026/02/12更新）を確認したところ、DMMには掲載されていなかった**AT初当たり確率**（設定1: 1/476 〜 設定6: 1/456、設定3非搭載の5段階設定に対応した5列）という数値テーブルが新たに見つかったため、①数値データに追加した。同ページの「終了画面」の項目は、示唆内容が「調査中」と明記されているのみで具体的な判別要素の記載がなかったため未採用。

## 数値データの細分化（2026-09-08）

東京喰種版で行った「①数値データのfield-group-label分割・新チャンネル追加」の横展開として、DMMぱちタウン「設定判別・推測ポイント」全文（終了画面系だけでなくボーナス・AT・演出情報の全セクション）と一撃のページを改めて精読した。

- **field-group-labelの分割**: 本ツールは元々「AT初当たり確率」「BAR揃い時のAT直撃当選率」がそれぞれ独立した見出しになっており、東京喰種版のような複数チャンネルが1見出しに同居する問題は発生していなかった。分割対象なし。
- **既存2チャンネルの再検証**: 「AT初当たり確率」（一撃、設定1: 1/476〜設定6: 1/456）と「BAR揃い時のAT直撃当選率」（DMM、設定1: 約3%〜設定6: 約7%）はいずれも最新のDMM/一撃ページの数値と完全に一致しており、変更なし。
- **新規に見つけたが採用しなかった数値テーブル**（いずれも理由付きで未採用）:
  - **ハラキリドライブ発生割合**（設定ごと）: DMMには「設定1〜3｜15〜20連に1回（約5%〜7%）」「設定4〜6｜6〜8連に1回（約13%〜17%）」という記載があるが、個別設定ごとの正確な数値ではなく2グループのレンジ表記であり、かつ本機には設定3が存在しないため「設定1〜3」という区分自体が5段階設定にそのまま当てはまらない。設定1・2・4・5・6それぞれの正確な値が判別できないため未採用。
  - **特定設定以上示唆が出る比率**（3000G/5000G/8000G消化時点、設定2〜6）: これはCZ・ボーナス終了画面や獲得枚数表示など、②のチップですでに個別カウントしている複数の濃厚演出が「いずれか1つでも出現する確率」を合算した集計値であり、独立チャンネルとして追加すると同じ演出出現という証拠を二重にカウントしてしまう。さらに設定1のデータが「一」（未記載）で欠落しているため、この点でも未採用。
  - **引き戻し当選率**（契機別：革命ボーナス後約9%／決戦ボーナス後約6%／AT後約20%／上位AT後約25%）: 契機ごとの値のみで設定別の内訳が一切公開されておらず、設定判別には使えないため未採用。
  - CZ・ボーナス終了画面の色別出現率、ゾロ目ゲーム数（＋22G等）、バッフェの出現割合、夢夢ちゃんプレミアム、マギウスマークの個数、獲得枚数表示——これらはDMMに設定別の出現率テーブルが載っているが、いずれも②のITEMSチップで「〜濃厚／〜示唆」として個別にカウント済みの演出であり、同じ演出出現をもう一度①の二項尤度チャンネルとして数値入力させると同一証拠の二重カウントになる。東京喰種版でもAT終了画面のキャラ別演出やトロフィー、エンディングカードなどは同様の理由でチップのみとし数値チャンネル化しなかったのと同じ方針を踏襲し、未採用とした。
  - ラウンド開始画面の出現率（10連目／20連目／30連目以降で分岐する複合テーブル）も、母数となる「◯連目時点」の判定が複雑でプレイヤーが正確に集計しづらいため、②のチップ判別（マリエ水着・ルーン漏れ1号機・200年後のサキ・リーゼロッテ）のみで扱う方針を維持。
  - 「初当りの革命ボーナス＋AT直撃比率」（設定2・4・5が調査中）、「特殊テーブル選択率」（内部モード前提で分母集計が困難）は、前回チェック時の未採用理由がいずれも現在のDMMページでも変わっていないことを確認した。
- **判別要素（ITEMSチップ）の再スキャン**: DMM演出情報セクション（ステージ示唆、アイキャッチ、連続演出期待度、会話演出の特殊示唆パターン、レア役ナビ等）も含めて確認したが、追加で拾うべき設定示唆の記載は見つからなかった。サブモニターの機体のヴァルヴレイヴ号機／PFネーム系／搭乗者マリエは演出情報セクションでも再掲されているのみで、いずれもモードや周期数の示唆でありREADMEの既存記載通り設定示唆ではないため引き続き未採用。

結果として、①②とも追加・変更すべき項目は見つからず、index.html自体への変更は無し（本セクションは監査の記録として追記）。

## データについて

- 「サブモニターの機体」のヴァルヴレイヴ3号機／5号機、PFネーム火ノ輪／火人／火遊、搭乗者野火マリエは、いずれも周期数やモード（マリエ覚醒など）に関する示唆であり、設定を示唆するものではなかったため未採用
- 「初当りの革命ボーナス＋AT直撃比率」はDMM記載が設定1・6のみで、設定2・4・5は「調査中」と明記されていたため、数値が不明な設定を補完せず未採用とした
- 「特殊テーブル選択率」は内部的な滞在状態（通常A〜C）を前提とした確率で、プレイヤーが分母となる試行回数を正確に数えるのが難しいため未採用とした

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 設定空間を`SETTINGS`配列で保持し、確率テーブルもオブジェクト（`{1: ..., 2: ..., 4: ..., ...}`）で持たせることで、5段階設定の機種にも対応できる形に一般化した
- チップUI・尤度計算の基本パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲
