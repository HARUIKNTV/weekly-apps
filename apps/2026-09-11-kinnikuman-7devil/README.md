# キン肉マン～7人の悪魔超人編～ 設定判別ツール

「スマスロ キン肉マン～7人の悪魔超人編～」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4378#anc-point)と関連特集記事、および[一撃「キン肉マン（スマスロ）」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_niku7devil/0/)（いずれも2026-09-11参照）に掲載されている判別要素を、AT初当り確率の数値データと示唆演出タップカウンターの2本立てで反映し、設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-11-kinnikuman-7devil/

## この機種の特徴：設定3が存在しない

DMMぱちタウン・一撃とも全テーブルが設定1・2・4・5・6の5列で構成されており、設定3は存在しない5段階設定の機種。本ツールも`SETTINGS = [1, 2, 4, 5, 6]`という設定空間で計算しており、結果表示にも設定3は出てこない（[革命機ヴァルヴレイヴ2](../2026-09-06-valvrave-2/)と同じ一般化パターンを踏襲）。

## 機能

- **数値データ**（①）: AT初当り確率（総G数・AT当選回数）を二項尤度チャンネルとして入力可能。空欄は「未入力」として扱い、0回成立と誤認しない（[モンスターハンターライズ版](../2026-09-07-monhun-rise/)の`parseField`パターンを踏襲）
- **判別要素**（②）: メニュー画面キャラクター、ケロットトロフィー（AT終了画面）、正義超人チャレンジ中の超人パワー上乗せ表示、エンディング中のレア役成立時キャラボイスの4カテゴリを、情報源の分類順のままタップ式カウンターで記録
  - 金文字表示の「〜濃厚」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と強さに応じて参考程度の重みだけを加える
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用

## データについて（採用・未採用の判断）

**採用した数値データ:**
- **AT初当り確率**（設定1: 1/404.1、設定2: 1/400.6、設定4: 1/362.1、設定5: 1/350.7、設定6: 1/336.5）— 複数の情報源で一致して確認できた唯一のクリーンな5段階フルテーブル。プレイヤーが総G数・AT当選回数を実戦で集計できる形式のため①の数値チャンネルに採用。

**確認できたが数値チャンネルとして未採用のデータ:**
- **機械割**（設定1: 97.9%〜設定6: 114.9%）— 出典は確認できたが、機械割はプレイヤーが試行回数(n)と成立回数(k)の形で実戦中に観測できる統計量ではない（AT初当り確率などの結果として導出される値）ため、二項尤度チャンネル化の対象外とした。
- **AT終了時の裏モード移行率**（設定1: 2.2%〜設定6: 2.7%という数値が複数の派生サイトで繰り返し引用されていた）— DMMぱちタウンの特集記事由来との言及はあったが、一撃側の該当ページ（「裏モード概要」）では「大きな設定差とは言えない」という定性的な説明に留まり、この具体的な5数値をどちらの一次情報源（DMMぱちタウンの機種ページ本体／一撃の設定差ページ本体）からも文言レベルで確認することができなかった。DATA-QUALITY GATEに従い、出典を一次情報源で裏付けできない数値は採用しないため、このテーブルは見送った。
- **弱チェリー／スイカ／チャンスベルの個別出現率** — 「合算で高設定ほど優遇」という記載のみで、設定ごとの個別確率・具体的な数値は「現状不明」と明記されていたため未採用。
- **裏モード滞在時のBAR揃いAT直撃当選率の設定差** — 「大きな設定差がある」と言及されるのみで、設定別のパーセンテージは一次情報源に見当たらなかったため未採用。
- **正義超人チャレンジLv1→Lv2昇格率／正義超人アタック突入率** — いずれも「高設定ほど優遇の可能性」という定性的な記載のみで、具体的な数値テーブルが見つからなかったため未採用。

**採用した判別要素（②のチップ）:**
- メニュー画面キャラクター（150万パワー到達後に変化）: 「わたしはレフェリー」（4以上濃厚）、「ナツコさん」（2以上濃厚）、ロビンマスク（偶数示唆）、テリーマン（高設定示唆[強]）
- ケロットトロフィー（AT終了画面）: トロフィー出現自体（2以上濃厚）、金トロフィー（4以上濃厚）、ケロット柄トロフィー（5以上濃厚）、虹トロフィー（6濃厚）
- 正義超人チャレンジ中の超人パワー上乗せ表示: ＋456パワー（4以上濃厚）、＋666パワー（6濃厚）
- エンディング中のレア役成立時キャラボイス: 「ビビンバ」ボイス（4以上濃厚）— この1件は一次情報源への直接的な帰属が他の要素よりやや弱く、確認の裏取りが1回にとどまったが、内容が「4以上濃厚」という具体的かつ曖昧さのない記述だったため採用した。

**確認できたが未採用の演出（設定示唆ではないため）:**
- メニュー画面のウォーズマン、ブラックホール、ステカセキング、バッファローマン、モンゴルマンなど: いずれも「SPモード発動が近い」という演出上の期待度示唆であり、設定を示唆するものではないため未採用。
- アイキャッチ色（緑／オレンジ濃い）、セリフ色（青＜緑＜紫）: いずれもSPモード期待度の示唆であり、設定示唆ではないため未採用。

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 設定空間を`SETTINGS`配列で保持し、確率テーブルもオブジェクト（`{1: ..., 2: ..., 4: ..., ...}`）で持たせることで5段階設定の機種に対応
- 数値入力欄は`parseField()`で空欄(`null`)と0回成立を区別し、`atInitialKRaw !== null`かつ総G数 > 0のときだけ二項尤度チャンネルを計算に含める
- チップUI・尤度計算の基本パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲
