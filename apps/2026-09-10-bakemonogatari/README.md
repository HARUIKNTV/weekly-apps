# スマスロ化物語 設定判別ツール

サミー「スマスロ 化物語」（西尾維新〈化物語〉シリーズ原作、アニメ制作：シャフト。2025年12月8日導入）の設定判別ファンメイド計算機です。

参考データ: [DMMぱちタウン「スマスロ 化物語」設定判別・推測ポイント](https://p-town.dmm.com/machines/4898#anc-point)（2026/09/01更新）／[一撃「化物語（スマスロ）」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_bakemonogatari/0/)（2026/06/17更新）

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-bakemonogatari/

## 機能

- 数値データ（総G数・AT当選回数・スイカ成立回数・弱チェリー契機のAT直撃・通常/高確滞在時のスイカ/チャンス目・強チェリー契機CZ当選率・200G/300G到達時のCZ当選率・AT中のボーナス確率）を独立した二項対数尤度チャンネルとして入力
- 空欄の数値項目は「データなし」として扱われ、0件（確定ハズレ）とは区別して計算から除外される
- AT終了画面のPUSHボタン一枚絵・サミートロフィー・ボーナス確定画面・獲得枚数表示の示唆演出をタップ式チップでカウント
  - 金文字の「◯以上濃厚／濃厚」は該当設定のみに候補を絞り込むハード除外
  - 斜体の「示唆」は候補を除外せず、softmax前の対数尤度に弱/通常/強の重みを加算するのみ（同一要素は3回まででカンスト）
- 各数値・示唆演出を統合したsoftmax正規化により、設定1〜6の期待度をバーとサマリーで表示

## 1geki.jpとのクロスチェック

- AT初当たり確率は一撃側のみに設定1〜6の完全な表があり（DMM側は機種概要欄の概況記載のみ）、一撃の数値（1/265.1〜1/219.6）を採用。
- スイカ確率・弱チェリーAT直撃当選率・AT中のボーナス確率は両サイトで完全に一致する数値を確認済み。
- 規定ゲーム数からのCZ当選率は、DMM表の列がずれて見えるため一撃の表と突き合わせて検証。100G到達時は全設定共通20.0%（設定差なし）であることを確認し、設定差が明確な200G・300G到達時のみをチャンネル化した。
- AT終了画面の「忍野」表記について、DMMは「設定3or5or6濃厚」、一撃は「設定1・2・4否定」と書き方が異なるが、論理的に同一の集合（{3,5,6}）であることを確認しITEMSに反映した。

## データについて（見つけたが採用しなかった項目）

- **AT終了時の解呪連移行率**（一撃）: 設定2の数値が欠落しており、補間の根拠がないため不採用。
- **通常滞在時の弱チェリー・強レア役成立時の高確移行率**（一撃）: 設定3の数値が欠落しているため不採用。
- **サミートロフィーのゲーム数消化域別・累積出現率**（DMM）: ゲーム数レンジごとに区切られた累積確率で、単純な二項尤度チャンネルとして組み込むには前提（母数の取り方）が煩雑になりすぎるため、チップ（銅/銀/金/キリン柄/虹＝◯以上濃厚）としてのみ採用し、数値チャンネル化は見送った。
- **ロングフリーズ・超ロングフリーズ確率**（DMM）: 単一の確率値のみが公開されており、設定差テーブルが存在しないため判別要素として採用しなかった。
- **エクストラサービス継続率のランプ色示唆**: 機械設定ではなくAT中の演出継続率（内部抽選）を示唆するもので、設定差データではないため対象外。

## 技術メモ
