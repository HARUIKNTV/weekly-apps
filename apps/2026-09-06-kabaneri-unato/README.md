# 甲鉄城のカバネリ 海門決戦 設定判別ツール

「スマスロ 甲鉄城のカバネリ 海門（うなと）決戦」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4930#anc-point)（2026/09/06更新）に掲載されている判別要素をそのままの分類（サミートロフィー／ST終了画面／カバネリアタック／おみくじ／キャラ紹介／逆押しサンド目ボイス／獲得枚数表示）で反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-06-kabaneri-unato/

## 機能

- **数値データ**（①）: 下段ベル確率、シングルチャンス目の3000pt獲得率、3周期目のボーナス当選率をそれぞれ独立した二項尤度チャンネルとして入力可能
- **判別要素**（②）: サミートロフィー、ST終了画面、カバネリアタックの連打上乗せ、おみくじ、カバネリボーナス中のキャラ紹介、逆押しサンド目停止時のボイス、獲得枚数表示のすべての要素を、DMMぱちタウンの分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 金文字表示の「〜濃厚」「〜否定」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と強さに応じて参考程度の重みだけを加える
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用

## データについて

- おみくじの「自決袋（設定1で出にくい）」「無名の短銃（設定3で出にくい）」「ツラヌキ筒（設定4で出にくい）」は、該当設定を除く全設定にわずかな重みを加える形で近似している（DMM側も「出にくい」という程度の表現で、明確な除外＝否定とは書かれていないため）
- 逆押しサンド目ボイスの「私は…ヒトか、カバネか！？」はDMM表記が「高設定示唆［中］」で、弱と強の中間の強度だったため、通常の示唆と同じ重み（tier: normal）に割り当てている
- 「CZ当選率は高設定ほど高い!?」は具体的な数値テーブルが同ポイント内になかったため未使用
- 「景之STループ」も定性的な説明のみで数値・明確な示唆パターンがなかったため未使用

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- チップUI・尤度計算の実装パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲
