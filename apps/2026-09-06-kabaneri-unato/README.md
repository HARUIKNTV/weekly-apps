# 甲鉄城のカバネリ 海門決戦 設定判別ツール

「スマスロ 甲鉄城のカバネリ 海門（うなと）決戦」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4930#anc-point)（2026/09/06更新）に掲載されている判別要素をそのままの分類（サミートロフィー／ST終了画面／カバネリアタック／おみくじ／キャラ紹介／逆押しサンド目ボイス／獲得枚数表示）で反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-06-kabaneri-unato/

## 機能

- **数値データ**（①）: 下段ベル確率、ボーナス初当たり確率、ST確率、シングルチャンス目の3000pt獲得率、3周期目・4周期目のボーナス当選率——計6系統をそれぞれ独立した二項尤度チャンネルとして入力可能（下段ベル・ボーナス初当たり・STの3チャンネルは総G数を共有）
- **判別要素**（②）: サミートロフィー、ST終了画面、カバネリアタックの連打上乗せ、おみくじ、カバネリボーナス中のキャラ紹介、逆押しサンド目停止時のボイス、獲得枚数表示のすべての要素を、DMMぱちタウンの分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 金文字表示の「〜濃厚」「〜否定」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と強さに応じて参考程度の重みだけを加える
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用

## 一撃（1geki.jp）とのクロスチェック（2026-09-07）

[一撃「カバネリ」設定差・設定示唆まとめ](https://1geki.jp/slot/l_kabaneri2/0/)（2026/09/04更新、この機種はDMMより新しい情報が反映されていた）を確認したところ、下段ベル確率・3周期目のボーナス当選率・おみくじ／ボイス／キャラ紹介などの判別要素はDMM記載の内容とすべて一致することを確認。さらに一撃独自の**4周期目のボーナス当選期待度**（設定1: 33.6% 〜 設定6: 46.9%）という新しい数値テーブルが見つかったため、数値データ①に追加した。
「小吉」の出現タイミング別の設定示唆（1〜5回目でそれぞれ対応する設定＋設定6が出現しやすい、という傾向）や、キャラ紹介・水着画面の出現率がゲーム数レンジ（0〜4000G／5000〜7000G／7000〜8000G）によって変動する詳細テーブルは、単純な出現回数カウントでは正確に条件を再現できないため未採用とした。

## 数値データの細分化（2026-09-08）

ユーザーからのフィードバックを受け、DMMぱちタウン（2026/09/07更新）と一撃（2026/09/04更新）の全ページ本文をあらためて読み直し、以下を追加・確認した。

- **新規採用**: 一撃「ボーナス初当たり/ST確率」の表に、設定1〜6まで欠落なしの完全なテーブルが掲載されていることを確認した（ボーナス初当たり確率: 設定1 1/254.2 〜 設定6 1/195.1、ST確率: 設定1 1/422.5 〜 設定6 1/318.5）。この2つは下段ベル確率とは全く別の独立した抽選のため、それぞれ**独立した数値チャンネル**（`P_BONUS_HIT`・`P_ST`）として追加した。総G数の入力欄は下段ベル確率の項目と共有する構成にした（DMM版東京喰種ツールの「総G数は上と共通」の表記パターンを踏襲）。
- 既存の4項目（下段ベル確率、シングルチャンス目の3000pt獲得率、3周期目・4周期目のボーナス当選率）はもともと1項目1見出しで独立しており、複数の異なる仕組みが同じ`field-group-label`にまとめられている箇所は見つからなかった（東京喰種ツールで見つかった「裏AT直行／100G以内／200G以内」のような相乗り状態は本機種には存在しない）。
- 判別要素（`ITEMS`配列）についても、DMM・一撃の両ページに掲載されているサミートロフィー、ST終了画面、カバネリアタック上乗せ、おみくじ、キャラ紹介、逆押しサンド目ボイス、獲得枚数表示の全項目が既に反映済みであることを再確認した。新規のチップ追加はなし。
- **今回もあえて未採用としたもの**（理由付き）:
  - サミートロフィーの「消化ゲーム数別トータル出現率」「色別詳細出現率」（1000G区切りで設定1〜6×トロフィー色ごとに値が変動する表）: 単発の出現回数カウントではゲーム数レンジという条件を再現できないため、ゲーム数レンジ依存の表として引き続き除外
  - ST終了画面の「水着画面の出現率（設定6）」のゲーム数レンジ別詳細（5000〜7000G・7000〜8000Gで出現率アップ）: 設定6のみのデータで他設定との比較ができないうえ、レンジ依存のため除外
  - カバネリボーナス中キャラ紹介の出現率振り分け（女性/男性/美馬、ゲーム数レンジ別）: 「美馬」列が設定1〜3で欠落（「ー」）しており、テーブルとして不完全なため除外。女性/男性キャラの比率自体はレンジごとに変動するため、これも引き続き除外
  - 「CZ出現確率は高設定ほど高い!?」「1・2周期のボーナス当選率は33%以上!?」「景之STループ当選率に設定差」: いずれも具体的な設定別数値が両ページとも未公開の定性的な記述のみのため未採用

## データについて

- おみくじの「自決袋（設定1で出にくい）」「無名の短銃（設定3で出にくい）」「ツラヌキ筒（設定4で出にくい）」は、該当設定を除く全設定にわずかな重みを加える形で近似している（DMM側も「出にくい」という程度の表現で、明確な除外＝否定とは書かれていないため）
- 逆押しサンド目ボイスの「私は…ヒトか、カバネか！？」はDMM表記が「高設定示唆［中］」で、弱と強の中間の強度だったため、通常の示唆と同じ重み（tier: normal）に割り当てている
- 「CZ当選率は高設定ほど高い!?」は具体的な数値テーブルが同ポイント内になかったため未使用
- 「景之STループ」も定性的な説明のみで数値・明確な示唆パターンがなかったため未使用
