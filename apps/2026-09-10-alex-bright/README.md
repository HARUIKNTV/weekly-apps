# アレックス ブライト 設定判別ツール

パチスロ「アレックス ブライト」（ユニバーサルブロス、2025年07月07日導入、型式名 LBAREXBRIGHTBA）の設定判別ツールです。DMMぱちタウン「アレックス ブライト」設定判別・推測ポイント（https://p-town.dmm.com/machines/4799 、2026/09/02更新時点で参照）に掲載されている数値データをもとに、実戦で取得した各種カウントから設定1〜6の期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-alex-bright/

## 機能

- 総G数ベースのBB当選率・RB当選率・羽（小役）成立率・3枚役成立率・チェリー成立率（合算）の5チャンネルを二項対数尤度で評価
- RB終了画面で背景が「壁画調（アレックス出現）」になる出現率（RB当選回数ベース）を追加のチャンネルとして評価
- 空欄の項目は「未入力（集計対象外）」として扱い、0回観測と区別（该当チャンネルのみスキップ）
- 各設定の尤度をsoftmax正規化し、期待度をバーグラフで表示

この機種は**設定3・4が存在しない4段階設定（設定1・2・5・6）**です。DMMぱちタウン・一撃（1geki.jp）双方の設定差テーブルがすべて設定1・2・5・6の4列のみで構成されており、設定3・4の数値は一切公開されていません。そのため `apps/2026-09-06-valvrave-2/index.html` と同じ `SETTINGS = [1, 2, 5, 6]` のオブジェクトキー方式を採用し、存在しない設定3・4を計算から完全に除外しています（補間・推測による代入は一切行っていません）。

## 1geki.jpとのクロスチェック

一撃「アレックス（スマスロ）」設定差・設定判別要素まとめ（https://1geki.jp/slot/lb_arexbright/0/ 、2025/08/27更新）のボーナス確率表・小役確率表・RB終了画面表は、DMMぱちタウン側の数値と完全に一致することを確認済みです（例：羽成立率 設定1 1/13.4、設定6 1/12.2、RB終了画面の壁画調出現率 設定1〜5 0.8%・設定6 5.0% など）。両サイトとも設定は1・2・5・6のみで、設定3・4は掲載されていません。

チェリーについては、DMMぱちタウンのテーブルがrowspan（複数設定で同じ値を共有する表組み）を使っており、生のテキスト抽出だけでは「一部の設定に値が無い」ように見える箇所がありました。実際にはHTMLのセル構造（`rowspan`属性）を確認し、リプレイ・チェリーA1・ブドウA/Bは全設定で共通の値（設定差なし）であり、羽・3枚役・チェリーA2・チェリーBのみ設定差があることを裏取りしています。またチェリーはA1/A2/Bの3種で構成され、停止型だけでは種別判別ができず（ユニメモ等の専用カウンターが必要）、1geki.jp側も「チェリー合算で判別する必要がある」と明記しているため、本ツールでは実戦で誰でもカウントできる「チェリー合算」の値を採用しています。

## データについて

- **見つかったが採用しなかったデータ**: BIG中（前半の小役ゲーム）の羽A・羽羽鳥A〜C・リーチ目役の成立率（設定差あり、DMM/1geki双方に掲載）は、BB中の消化ゲーム数という特殊な分母が必要で、通常のG数カウントだけでは正確な試行回数を取れないため、カジュアルな入力を想定する本ツールでは採用を見送りました。
- **見つからなかったデータ（判別要素チップ）**: 東京喰種やヴァルヴレイヴ2のようなキャラクター絵柄・トロフィー等の「濃厚/否定」「示唆」タイプの視覚的判別要素は、2026/09/10時点でDMMぱちタウン・一撃のいずれにも掲載されていません（DMMぱちタウンの「設定判別・推測ポイント」内は終了画面系のRB終了画面のみ、天井突入条件は「調査中」表記）。そのため本ツールの `ITEMS` 配列は空のまま保持しており、チップは一切表示されません。存在しない要素を補うための架空のチップは作成していません。今後DMM側でデータが追加された場合は本ツールも更新予定です。
- **設定3・4**: 前述の通り、この機種はそもそも4段階設定（1・2・5・6）であり、設定3・4は存在しません。捏造・補間は行っていません。

## 技術メモ

`apps/2026-09-06-tokyo-ghoul-slot-checker/index.html` のCSS（白／黒／赤基調のテーマ）・HTML骨格・JSアーキテクチャ（`logBinomLikelihood` による二項対数尤度、`computeCandidateSettings` によるhard要素の候補絞り込み、`buildChips` によるチップ生成、softmax正規化、フィードバックウィジェット）をベースに、`apps/2026-09-06-valvrave-2/index.html` の `SETTINGS` オブジェクトキー方式（存在しない設定の除外）と `apps/2026-09-07-monhun-rise/index.html` の `parseField`（空欄＝未入力として0と区別するブランクフィールド安全策）を組み合わせて実装しています。
