# パチスロ甲鉄城のカバネリ（初代）設定判別ツール

2022年7月導入のSammy「パチスロ甲鉄城のカバネリ」（型式名: S パチスロ甲鉄城のカバネリ ZR、6.5号機第1弾）の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4160#anc-point)（2026/09/09更新）に掲載されている判別要素をそのままの分類（サミートロフィー／ST終了画面／おみくじ／カバネリアタック無名の上乗せ枚数／カバネリボーナス中の紹介画面／獲得枚数表示）で反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。

**この機種はスマスロ「甲鉄城のカバネリ 海門（うなと）決戦」（[apps/2026-09-06-kabaneri-unato/](../2026-09-06-kabaneri-unato/)、DMM機種ID: `4930`、2026年3月導入）とは別の、より前に登場した機種です。** 本ツールが対象とするのは初代機（DMM機種ID: `4160`、2022年7月導入）で、海門決戦とはゲーム性・設定差データともに完全に別物のため、機種ページ・演出名も重複しません（データ取り違え防止のため、DMM機種IDを本README・ツール内の両方に明記しています）。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-kabaneri-original/

## 機能

- **数値データ**（①）: 共通6枚ベル確率、CZ当選率（無名+生駒+美馬合算）、ボーナス/ST初当り確率、規定ゲーム数（100G／250G／450G／650G）ごとのボーナス当選率、無名CZ中の2択ナビ発生率、無名CZ・3連撃到達時のCZ成功率、無名CZ/生駒CZ失敗時のBBランクアップ率、ST終了画面「菖蒲」出現率——計12系統をそれぞれ独立した二項尤度チャンネルとして入力可能（共通6枚ベル・CZ当選率・ボーナス/ST初当り確率の4チャンネルは総G数を共有、規定ゲーム数の4チャンネルはゾーンごとに到達回数が異なるためそれぞれ独立した見出し・分母を用意）
- **判別要素**（②）: サミートロフィー、おみくじ、カバネリアタック「無名」の上乗せ枚数、獲得枚数表示、カバネリボーナス中の紹介画面（第七話／男性キャラ／女性キャラ）を、DMMぱちタウン・一撃の分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 「〜濃厚」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 「奇数設定示唆」「偶数設定示唆」（キャラ紹介の男女比率）は確定情報ではないため、ハード除外はせず出現回数に応じて参考程度の重みだけを加える
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用
- サイト共通の「ご意見・ご要望」フィードバックウィジェット（右下の💬ボタン）を搭載

## データについて（見つけたが不採用にしたもの・理由付き）

- **サミートロフィーの「総ゲーム数別・トロフィー出現率」**（5000G以下／5001〜7000G／7001G以降の3レンジ×5色の詳細表）: 単発の出現回数カウントではゲーム数レンジという条件を再現できないため、ゲーム数レンジ依存の表として除外（トロフィー色ごとの閾値自体＝「銅＝2以上濃厚」等は判別要素チップとして採用済み）
- **CZのポイント減算数**（単独チャンス目／複合チャンス目成立時の15pt/30pt/60pt/120pt振り分け）: 1回の抽選結果が4択の多項分布（categorical）になっており、本サイトの他ツールと同じ二値（的中/非的中）の二項尤度チャンネルの枠組みでは正確に再現できないため不採用
- **カバネリアタック「無名」の上乗せトータル発生確率**（設定4: 約1/544、設定5: 約1/537、設定6: 約1/614、設定1〜3は「－」＝発生なし）と**特定枚数獲得時の出現確率**（456枚OVER: 設定4・5で約1/131、666枚OVER: 設定6で約1/218等）: いずれも該当する演出（+44枚等・456枚OVER等）自体を判別要素チップとして「◯以上濃厚」の形で既に反映済みのため、数値チャンネルとしての二重計上を避けて不採用
- **BBランク+3UP昇格率**（無名CZ/生駒CZ失敗時）: 一撃の表で全設定共通0.4%であることが確認でき、設定差がないため不採用（+1UP列のみ採用）
- **美馬CZ失敗時のランクアップ率**（全設定共通 約88〜90%）: 設定差なしのため不採用
- **初期ボーナスランク振り分け**（設定1のみ公開）、**駿城ボーナスのポイント別ST当選期待度**（設定1のみ公開）、**駿城カウンタ加算当選率**（設定差の記載なし）: 比較対象となる他設定のデータが公開されていない、または設定差の記載がないため判別要素として使えず不採用
- **無名CZ・連撃数別のトータル勝利期待度**、**生駒CZの無敵抽選**、**美馬CZの成立役別成功期待度**: いずれも設定1のみの数値、または設定差の記載がないため不採用
- **ボーナスランク示唆演出**（キリ番演出・駿城ボーナス終了画面のキャラ出現分布）: ◎○△－の定性的な傾向表記のみで具体的な確率値が公開されていないため不採用
