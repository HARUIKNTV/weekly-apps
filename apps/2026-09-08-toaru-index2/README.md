# スマスロ とある魔術の禁書目録2 設定判別ツール

「とある魔術の禁書目録2」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/5053#anc-point)（2026/09/08更新）に掲載されている判別要素をそのままの分類（藤丸コイン→AT終了画面→獲得枚数表示→エンディング）で反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-08-toaru-index2/

## 機能

- **数値データ**（①）: 以下5つの独立した二項尤度チャンネルを、共有する母数ごとに2つの見出しにまとめて入力可能
  - CZ・AT当選率（総G数ベース、共通の「総G数」入力欄を使用）
    - CZ出現率（超電磁砲・一方通行CHANCE合算、設定1: 1/235.6〜設定6: 1/207.2）
    - AT初当たり確率（CZ経由＋AT直撃の合算、一撃調べ・DMM非掲載、設定1: 1/398.8〜設定6: 1/338.4）
    - AT直撃当選率（実ゲーム天井到達・超レア役成立を除く、設定1: 1/7926.8〜設定6: 1/3736.2）
  - 通常時のスイカ契機の内部状態移行率（共通の「通常状態時のスイカ成立回数」を母数として使用）
    - 高確移行率（設定1: 47.7%〜設定6: 55.5%）
    - 美琴高確移行率（設定1: 14.3%〜設定6: 16.7%。高確状態時からの移行率30.1%は全設定共通のため対象外）
- **判別要素**（②）: DMMぱちタウンに掲載された全4カテゴリ・30種類の演出を、DMMの分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 藤丸コイン（5種）: 銅／銀／金／デンジャー柄／虹 — すべて金文字の「〜濃厚」
  - AT終了画面（7種）: 当麻＆インデックス（奇数示唆）・美琴＆黒子（偶数示唆）・一方通行の高設定示唆2種（弱／中）に加え、アリサ＆シャットアウラ・初春＆美琴・当麻ハーレムの濃厚3種
  - 獲得枚数表示（9種）: 174枚 OVER〜1777枚 OVERまで — すべて金文字の「〜濃厚」
  - エンディング：レア役時のセリフ（9種）: 奇数／偶数示唆、高設定示唆［弱／中］に加え、「やったあ！」〜「おめでとう！（虹）」の濃厚5段階
  - 金文字表示の「〜濃厚」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と［弱/中］の強さに応じて参考程度の重みだけを加える
- タップ式のカウンターUI（コンパクトな一覧チップ表示でページを短く保つ）
- 数値データとカウント結果を組み合わせて、現在の有力候補と最有力設定をリアルタイム表示
- 広告枠（`.ad-slot`）を3か所設置：ヘッダー直下（728×90）、判別要素と結果の間（300×250）、フッター上（728×90）。今はプレースホルダー表示のみ（詳細はリポジトリルートのREADME「広告の設置について」を参照）

## 一撃（1geki.jp）とのクロスチェック（2026-09-09）

[一撃「とある魔術の禁書目録2（インデックス2）」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_toaru_index2/0/)（2026/08/10更新）を確認したところ、CZ出現率・AT直撃当選率・スイカ契機の高確／美琴高確移行率・獲得枚数表示・藤丸コイン・AT終了画面（設定示唆分）・エンディングのセリフ演出は、いずれもDMMぱちタウン側の数値・示唆内容と完全に一致していた。

AT初当たり確率（設定1: 1/398.8〜設定6: 1/338.4）はDMMぱちタウン側には掲載されておらず、一撃側にのみ掲載されている独立した数値テーブルだったため、コード中のコメントに「一撃調べ」と明記した上でそのまま採用している。

## データについて

以下は両サイトを確認したが、設定差ではなく別の情報のため採用しなかった項目：

- **AT終了画面の残りゲーム数示唆**（アイテム集合＝残り500G以内濃厚／スクール集合＝残り300G以内濃厚／グループ集合＝残り150G以内濃厚／カエル顔の医者＝AT復活濃厚）: DMM・一撃の両方に掲載されているが、これは隠し設定ではなく天井到達までの残りゲーム数を示唆する演出であるため、判別要素の対象外とした
- **高確状態時からの美琴高確移行率（30.1%）**: DMMの内部状態移行率テーブルでは設定1の行にのみ数値が記載され、設定2〜6の欄は空欄になっている。これは全設定共通のため省略されている表記であり、設定差判別には使えないため対象外とした（通常状態時からの移行率のみ設定差ありのため採用）
- **藤丸コインの店舗カスタム仕様**（一撃「店舗カスタムについて」）: 消化ゲーム数帯ごとに藤丸コインの出現率を店舗側で変更できる仕様があるとの記載だが、これは店舗設定であり遊技機本体の設定差ではないため判別要素には含めていない
- **超電磁砲／一方通行CHANCEのAT期待度（約52%／約80%）**: CZそのものの性能値であり、設定別の数値は記載されていないため対象外とした

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算: 各数値チャンネルの二項分布 `P(k|n,p)` の対数尤度を合算し、示唆要素は出現回数（上限3回でキャップ）×tier別の重み（弱0.2／通常0.35／強0.5）を加算。その後ソフトマックス的に正規化（一様事前分布を仮定）
- 実装パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲：`numericInputs`配列（id列挙順）→イベントリスナー（`numericInputs.forEach((el) => el.addEventListener('input', render))`）→`render()`内の分割代入、の3点の並び順を完全一致させて配線漏れを防止
- CZ出現率・AT初当たり確率・AT直撃当選率の3チャンネルは総G数を共通の母数とするため、`totalG`の入力欄は1つだけ用意。高確移行率・美琴高確移行率の2チャンネルも同様に「通常状態時のスイカ成立回数」を共通の母数とするため`suikaN`は1つのみ（東京喰種ツールの下段リプレイ・AT直撃グループと同じパターン）
- AT初当たり確率はCZ経由＋AT直撃の合算値（一撃調べ）のため、厳密にはAT直撃チャンネルと観測対象が一部重複する可能性があるが、実用上の簡易計算として東京喰種ツールと同様に各チャンネルを独立とみなして割り切っている
