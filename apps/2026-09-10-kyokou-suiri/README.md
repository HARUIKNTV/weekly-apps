# スマスロ「L 虚構推理」設定判別ツール

D-light「L虚構推理」（スマスロ、2026年4月6日導入開始）の設定判別ファンメイド計算機です。
DMMぱちタウン「L虚構推理（スマスロ）パチスロ｜設定判別・天井・ゾーン・解析・打ち方・ヤメ時」の
「設定判別・推測ポイント」（https://p-town.dmm.com/machines/4973 、2026/09/09更新確認）に掲載されている
各種確率テーブルと示唆演出を数値化し、二項対数尤度＋softmaxで設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-kyokou-suiri/

## 機能

- **① 数値データ**：わかる範囲で入力するほど精度が上がる5つの独立チャンネル（空欄＝未計測として無視、0＝実測ゼロとして計算に反映）
  - ボーナス・CZ当選率（総G数ベース。ボーナス初当たりとCZ当選をそれぞれ独立集計）
  - 低確滞在時の弱チェリー・スイカ成立時のCZ当選率
  - 弱チェリー・スイカ成立時の高確移行率（保証30G当選）
  - CZ突入時の確定CZ（一発クリア）当選率（nは①のCZ当選回数を共用）
  - エピソード開始時のクリア当選率
- **② 判別要素**：5カテゴリ・31個のタップ式カウンターチップ
  - ダイナマイトトロフィー（ボーナス終了画面）
  - 虚構推理ボーナス（スーパー）終了画面
  - あやかしボーナス中のキャラ紹介
  - エンディング中のセリフ＆ランプ色
  - 初回CZ開始エピソード数（虚構連モード駆け抜け時・設定変更時以外）
  - 金文字の「濃厚/否定」はハード制約（候補設定を確定・除外）、斜体の「示唆」は参考程度の重み付けのみ
- **③ 結果**：設定1〜6の期待度をバー表示し、矛盾時は警告、無データ時は案内を表示

## 1geki.jp クロスチェック

一撃「【虚構推理（スロット/スマスロ）】設定差・設定判別要素まとめ｜終了画面に注目！」
（https://1geki.jp/slot/l_kyokousuiri/0/ 、最終更新日 2026年04月27日）でも同じ数値・示唆内容を確認し、
ボーナス初当たり確率・CZ出現率・低確滞在時レア役CZ当選率・高確移行率・確定CZ当選率・エピソードクリア当選率・
ダイナマイトトロフィー・虚構推理ボーナス終了画面・あやかしボーナス中のキャラ紹介・エンディング示唆のすべてで
DMM側の数値と一致することを確認済みです。
なお、あやかしボーナス中の「赤背景キャラ紹介」について、1geki.jpは「赤背景＝特定設定否定」とまとめて説明する一方、
DMM側は1人目/2人目/3人目でそれぞれ設定1/2/3否定と個別に紐付けているため、本ツールではより詳細なDMM側の内訳を採用しています。
また、桜川六花の名前表記について1geki.jp側に「桜川立花」という誤記とみられる表記揺れがあったため、DMM側の正しい表記「桜川六花」を採用しました。

## データについて

以下は両サイトで確認したものの、精度・実用性の観点から本ツールには組み込みませんでした。

- **共通ベル時のCZ・ボーナス直撃当選率**：設定差データ自体は存在するものの（例：CZ直撃 1/2822.1〜1/2427.4）、共通ベル（約1/21で成立）を実戦中に正確に数え続けるのは非現実的で、集計誤差が結果を大きく歪めるおそれがあるため見送りました。
- **天井ゲーム数振り分け（300G短縮天井など）**：天井到達という稀な単発イベントの内訳であり、通常プレイ中に繰り返し観測できる二項分布データとして扱うのに適さないため見送りました。
- **高確移行率の「15G」「非当選」側**：同一テーブルの「30G」側（最も設定差が大きい枝）をすでに採用しており、同じ情報源からの重複チャンネル化を避けるため見送りました。
- **CZ間100G消化ごとのCZ当選率（100G・200G刻み）**：DMM側で「調査中」と明記されており実データが存在しないため見送りました（捏造防止）。
- **CZの引き戻し当選率**：終了時のエピソード段階別の値のみで、設定ごとの内訳が公開されていないため見送りました。
- **虚構連モードの転落確率**：設定1・6のみ数値が公開されており、設定2〜5が欠落した不完全なテーブルのため見送りました。
- **ボーナス昇格ゾーン（虚構真偽）当選率**：成立役別の値のみで設定差テーブルが存在しないため見送りました。
- **「出没!?鋼人七瀬」等の連続演出の期待度テーブル**：これらはCZ以上の期待度を示すゲーム内演出であり、設定差そのものを示す情報ではないため対象外としました。
- **琴子・六花ステージでの虚構連モード示唆**：虚構連モード（ボーナス後の内部状態）に関する示唆であり、設定差とは別軸の情報のため対象外としました。

## 技術メモ

`apps/2026-09-06-tokyo-ghoul-slot-checker/` の実装をベースに、CSS（白/黒/赤パレット）・HTML骨格・JSアーキテクチャ
（`logBinomLikelihood` による二項対数尤度、`computeCandidateSettings` によるハード制約の集合演算、`buildChips` による
カテゴリ別チップ生成、softmax正規化による`render`）をそのまま踏襲しています。
空欄フィールドの安全な扱い（`parseField` が空文字列を`null`として区別し、各チャンネルは自身のフィールドが非nullの場合のみ
計算に加算する）は `apps/2026-09-07-monhun-rise/` の実装パターンを踏襲しています。
フィードバックウィジェット（画面右下の💬ボタン、FormSubmit.co経由でメール送信）も同ファイルから変更なく流用しています。
