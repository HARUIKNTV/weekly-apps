# スマスロガンダムユニコーン2 設定判別ツール

「Lパチスロ 機動戦士ガンダムユニコーン 覚醒DRIVE」（ビスティ、2026年4月20日導入）の設定判別ツールです。[DMMぱちタウンの機種ページ](https://p-town.dmm.com/machines/5002)（設定判別・推測ポイント、2026/09/10更新時点で確認）に掲載されている実データをもとに作成しています。導入から約5か月が経過しており、設定判別・推測ポイントのセクションは「準備中」ではなく実データが公開されている状態でした。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-gundam-unicorn/

## 機能

- ① 数値データ：AT初当り回数・CZ当選回数（総G数ベース）、スタンバイ状態移行時のキャラ出現率（男性/女性）を入力すると、設定1〜6ごとの二項対数尤度を計算
- ② 判別要素：AT終了画面／エンディング終了画面／CZ中の裏ボタン（PUSH回数）／獲得枚数表示／エンディング中のレア役ランプ色／MSジャッジ成功時の裏ボタン（上位AT中）の出現回数をタップでカウント。「濃厚/否定」は候補を確定・除外するハード要素、「示唆」は重みだけを加えるソフト要素として区別
- ③ 結果：softmax正規化した設定期待度をバー表示、矛盾時は警告表示

## データについて

DMMぱちタウンおよび[一撃「ユニコーン（スマスロ）」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_gundam_uc2/0/)（2026/05/22更新）の両方を確認し、クロスチェックしました。両サイトの数値・示唆内容はほぼ一致していたため、確率テーブルは1〜6すべての設定値が判明している一撃側の数値を採用し、質的な示唆演出（終了画面・裏ボタン等）はDMMぱちタウンの表記に揃えています。

以下は「発見したが採用しなかったデータ」です（理由付き）。

- **CZ当選期待度（破壊役/覚醒役成立時、通常/高確/超高確別）**：設定1の数値のみ判明しており、設定2〜6は両サイトとも「???」表記で未公開。設定2〜6を補間・推測すると実データのない値を捏造することになるため、この項目は丸ごと除外しました。
- **高確移行抽選（破壊役成立時の高確/超高確移行率）**：同様に設定1のみ判明・設定2〜6は「???」のため除外。
- **CZ中の裏ボタンのPUSH回数のうち5回（示唆なし）・11回（ミネバボーナス濃厚）・12回（上位AT濃厚）**：いずれも設定を絞り込む情報を含まない（ボーナス種別やAT階層の示唆であり設定示唆ではない）ため、判別要素チップには含めていません。
- **MSジャッジ成功時の裏ボタン（導光板の色）**：色そのもの（白・赤・虹）は獲得枚数の示唆であり単独では設定差がないため、「法則が崩れた場合（赤なのに100枚／虹なのに500枚）」の2パターンのみを設定濃厚要素として採用しました。

なお、この機種は設定1〜6の6段階すべてが公開データに揃っているため（設定3が存在しないヴァルヴレイヴ2のような欠番はない）、`SETTINGS`配列による設定除外は行わず、通常の6要素配列で確率テーブルを実装しています。

## 技術メモ

`apps/2026-09-06-tokyo-ghoul-slot-checker/`をベースに実装しました。CSS（白/黒/赤テーマ）、HTML骨格、二項対数尤度によるsoftmax正規化、タップ式カウンターチップ、フィードバックウィジェット（FormSubmit.co経由、メールクライアント不要）はすべて同ツールの実装パターンを踏襲しています。空欄の数値フィールドは「データなし」として扱い（`apps/2026-09-07-monhun-rise/`の`parseField`パターンを採用）、確定ゼロ回として誤って計算に含めることのないようにしています。
