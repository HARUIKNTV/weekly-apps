# 炎炎ノ消防隊2 設定判別ツール

「Lパチスロ 炎炎ノ消防隊2（スマスロ）」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4926#anc-point)（2026/09/06更新）に掲載されている判別要素をそのままの分類（ボーナス終了画面／REG中のキャラ紹介／エンディング／獲得枚数表示）で反映し、示唆演出の出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-06-enen-shouboutai-2/

## 機能

- **数値データ**（①）: 炎炎ループ初当たり確率・ボーナス初当たり確率（一撃調べ）を独立した二項尤度チャンネルとして入力可能
- **判別要素**（②）: ボーナス終了画面の設定示唆画面、REG中のキャラ紹介（シナリオ・まもるくんの出現順・特定濃厚キャラ）、エンディングのミニキャラ、獲得枚数表示のすべての要素を、DMMぱちタウンの分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 金文字表示の「〜濃厚」「〜否定」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と強さに応じて参考程度の重みだけを加える
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用

## 一撃（1geki.jp）とのクロスチェック（2026-09-07）

[一撃「炎炎ノ消防隊2」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_ennenn2/0/)（2026/02/04更新）を確認したところ、DMMぱちタウンには掲載されていなかった**炎炎ループ初当たり確率**（設定1: 1/684 〜 設定6: 1/486）と**ボーナス初当たり確率**（設定1: 1/272 〜 設定6: 1/227）という2つの数値テーブルが新たに見つかったため、①数値データのカードを新設して追加した。判別要素（チップ）側に新規追加できるものはなかった。

## 数値データについて

DMMぱちタウン「設定判別・推測ポイント」内には、他機種にあるような単純な設定1〜6の数値テーブル（CZ確率など）が見当たらなかったため、判別要素（チップ）のみで構成していたが、一撃（1geki.jp）側で上記2テーブルが見つかったため現在は①数値データのカードも存在する。「小Vリプレイの十字目変換発生率＆期待度」は設定1と「高設定（設定4以上!?）」の2グループしかデータがなく、設定2・3・5・6の個別値が不明なため、誤った補間を避けるためにあえて未使用としている。

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 「まもるくんが1〜5番目に出現→該当設定否定」は、記事本文の「出現した順番の設定を否定（1番目に出れば設定1否定）」というルール説明から、2〜5番目についても同様のパターンとして構成した
- チップUI・尤度計算の実装パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲
