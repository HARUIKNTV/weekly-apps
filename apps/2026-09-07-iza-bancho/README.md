# スマスロいざ番長 設定判別ツール

「いざ！番長」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4805#anc-point)（2026/09/07更新、全文）と[一撃「いざ番長」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_bancho_iza/0/)（2026/07/06更新、全文）の両方を読み込み、両サイトに掲載されている完全な設定1〜6テーブルと示唆演出をゼロから反映して構築した。本機は全機種共通で「奇数設定は荒波、偶数設定は安定」という設計傾向があるとする情報が検索結果に見られたが、今回読み込んだ2つの参考ページにはこの傾向を直接裏付ける記述が見当たらなかったため、未確認の噂として本文には反映していない（唯一の設定パリティ関連の示唆は、AT終了画面「子育て奮闘」の偶数設定示唆のみ）。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-07-iza-bancho/

## 機能

- **数値データ**（①）: 以下7系統をそれぞれ独立した二項尤度チャンネルとして入力可能
  - 共通ベルA確率（1/74.9〜1/58.0）・弱チェリー確率（1/79.9〜1/77.6）— 総G数ベースで共有
  - 番長ボーナス直撃確率（赤7: 1/8156.2〜1/2495.8、青7: 1/220772.4〜1/22560.5）— 総G数は上と共通
  - 初当り合算確率（1/386.9〜1/312.1、一撃調べ・DMM非掲載）— 総G数は上と共通
  - 刀ポイントMAX時の抜刀AT当選率（3.1%〜4.3%、刀レベル1・2共通値）
  - 絶頂決戦～巌流島～突入時のミーモ斬シング発生率（6%〜16%）
- **判別要素**（②）: DMMぱちタウン「終了画面系＞AT終了画面」に掲載された全7演出（子育て奮闘・護摩行・刺客襲来・小太郎日記・青龍／武蔵・朱雀／小次郎・秘湯）を、DMMの分類のままカテゴリラベル付きでタップ式カウンターで記録
  - 金文字表示の「〜濃厚」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と強さに応じて参考程度の重みだけを加える
- タップ式のカウンターUI（コンパクトな一覧チップ表示でページを短く保つ）
- 数値データとカウント結果を組み合わせて、現在の有力候補と最有力設定をリアルタイム表示
- 広告枠（`.ad-slot`）を3か所設置：ヘッダー直下（728×90）、判別要素と結果の間（300×250）、フッター上（728×90）。今はプレースホルダー表示のみ（詳細はリポジトリルートのREADME「広告の設置について」を参照）

## 一撃（1geki.jp）とのクロスチェック

DMMぱちタウンと一撃の両方を全文読み比べた結果、重複する数値テーブル（共通ベルA・弱チェリー確率、番長ボーナス直撃確率、刀ポイントMAX時のAT当選率、AT終了画面の示唆内容）はすべて完全に一致していた。一撃側にのみ掲載されていた**初当り合算確率**（設定1: 1/386.9〜設定6: 1/312.1）は、DMMには存在しない独立した数値テーブルだったため新たに数値チャンネルとして採用した。

逆に、DMM側の「絶頂決戦のミーモ斬シング発生率」（設定1: 約6%、設定2: 約6%、設定3: 約10%、設定4: 約6%、設定5: 約16%、設定6: 約16%）は設定1〜6まで完全なテーブルだったが、一撃側の同じ表は設定2・設定6の値が空欄で欠落しており不完全だった。この場合はDMM側の完全なテーブルを採用した。

## データについて

以下は両サイトを確認したが、理由があって採用しなかった項目：

- **刺客ゾーン（CZ）枠色（青／黄）ごとのAT当選率**: DMM「設定2は↓、設定3は↓…」、一撃「設定2〜5は???」と、いずれも設定1（青1.0%／黄10.0%）と設定6（青3.0%／黄15.0%）の両端しか具体的な数値が掲載されておらず、設定2〜5の個別値は不明。誤った補間を避けるため未採用とした。
- **刀ポイントMAX時のCZ当選率**: 「※CZ当選率は全設定」と明記されている通り、この値は設定によらず一定（刀レベル1: 30.1%、レベル2: 46.9%、レベル3: 87.5%）であり設定差がないため、判別要素として使う意味がない。設定差があるAT当選率の方だけを採用した。
- **刀レベル3時のAT当選率**: 設定1の12.5%のみ判明しており、設定2〜6のデータが両サイトとも欠落。レベル1・2は全設定で判明しているため、そちらを採用しレベル3は見送った。
- **実戦上のAT突入時の成敗報酬「将軍」所持率**（一撃）: 設定5（5/7＝71.4%）と設定6（3/8＝37.5%）の実戦値のみが掲載されており、設定1〜4のデータが存在しない。サンプル数も一桁と少なく「自社調査」の実戦値にとどまるため未採用とした。
- **絶頂決戦～巌流島～の突入率**（一撃「設定5は突入率が優遇!?」）: 具体的な設定別数値を伴わない推測表現のみで、公開されている完全なテーブルが存在しないため未採用とした。
- **御免ポイントの獲得示唆／蓄積示唆**（DMM、弱・中・強の3段階）: 内容を確認したところ、これは獲得・保有しているポイント量（1pt以上／10pt以上／50pt以上など）を示す演出であり、隠し設定とは無関係のゲーム内リソース表示だったため、判別要素として採用しなかった。
- **モード示唆系演出**（ステージチェンジ、浮世絵ウインドウ、リプレイフラッシュ等）、**修行中の演出法則**、**対決・ストーリー演出**、**決闘・上乗せ系の演出法則**、**強決闘以上に期待できる演出**、**裏ボタン（家紋ランプ）の示唆**: いずれも通常時のモード（チャンスA／チャンスB／天国）やAT中の抽選（決闘勝利・上乗せ枚数など）を示唆するものであり、隠し設定そのものを示唆する内容ではないため対象外とした。
- **白・緑・赤・虹オーラ（刺客ゾーン）でのAT当選率**: 一撃に「全設定共通」と明記されており設定差がないため対象外。ただし虹オーラの「AT＋番長ボーナス濃厚」は設定ではなく獲得内容の示唆のため、そもそも判別要素にはあたらない。

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算: 各数値チャンネルの二項分布 `P(k|n,p)` の対数尤度を合算し、示唆要素は出現回数（上限3回でキャップ）×tier別の重み（弱0.2／通常0.35／強0.5）を加算。その後ソフトマックス的に正規化（一様事前分布を仮定）
- 実装パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲：`numericInputs`配列（id列挙順）→イベントリスナー（`numericInputs.forEach((el) => el.addEventListener('input', render))`）→`render()`内の分割代入、の3点の並び順を完全一致させて配線漏れを防止
- 「共通ベルA・弱チェリー確率」「番長ボーナス直撃確率（赤7／青7）」「初当り合算確率」の5チャンネルはすべて母数が同じ「総G数」のため、`totalG`の入力欄は1つだけ用意し、各`field-group-label`の見出しに「総G数は上と共通」と明記して重複入力を避けた（東京喰種ツールの下段リプレイ・AT直撃グループと同じパターン）
- 「刀ポイントMAX時の抜刀AT当選率」と「絶頂決戦のミーモ斬シング発生率」は母数（分母）がそれぞれ「刀ポイントMAX到達回数」「絶頂決戦～巌流島～突入回数」という別の分母を持つ独立した抽選のため、それぞれ専用の見出しと入力欄を分けた
- 番長ボーナス直撃確率は赤7・青7が排他的な事象のため、厳密には母集団の重複は無いが、初当り合算確率はCZ経由・直撃経由などを含む上位集計であり、他チャンネルと観測対象が一部重複する可能性がある。実用上の簡易計算として、東京喰種ツールと同様に各チャンネルを独立とみなして割り切っている
