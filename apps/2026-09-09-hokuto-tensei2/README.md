# スマスロ「北斗の拳 転生の章2」設定判別ツール

サミー「スマスロ 北斗の拳 転生の章2」（2026年1月5日導入）の設定判別ファンメイド計算機です。[DMMぱちタウンの機種ページ](https://p-town.dmm.com/machines/4909)（「設定判別・推測ポイント」セクション、2026/09/04更新時点）に掲載されている数値データ・示唆演出の出現率をもとに、入力した実戦データから設定1〜6の期待度を対数尤度ベースで算出します。

※本機は2023年導入の初代「スマスロ北斗の拳」とは別機種です。混同しないようご注意ください。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-09-hokuto-tensei2/

## 機能

- **① 数値データ**：以下4つのチャンネルを独立した二項尤度として計算します。
  - AT初当たり回数・天破の刻当選回数（総G数ベース、n共有）
  - 設定変更（リセット）後の規定あべし256以内当選率
  - 天撃（上位CZ）成功率＝上位AT当選率
  - 筐体上部ランプB「白点灯／白点滅」比率（設定2・4は点灯寄り、設定3・5は点滅寄り、設定1・6は五分）
  - 各欄は空欄なら「データなし」として扱われ、0を入力したときとは区別して計算から除外されます。
- **② 判別要素**：サミートロフィー（銅〜虹）と筐体ランプB（水色・黄緑・金）の出現をタップでカウント。「濃厚/否定」は設定候補をハード確定・除外し、「示唆」は参考程度の重みだけを加算します。
- **③ 結果**：設定1〜6の相対期待度をバーで表示し、矛盾する濃厚/否定が同時カウントされた場合は警告を出します。

## 1geki.jpとのクロスチェックについて

DMMぱちタウンは天破の刻・256あべし以内当選率・天撃成功率などをゾーン別の複雑な内訳表で掲載していますが、[一撃（1geki.jp）の「設定差・設定判別要素まとめ」](https://1geki.jp/slot/l_hokuto_tensei2/0/)（2026/05/03更新）には同じ数値が単一の設定1〜6テーブルとしてまとまっており、本ツールの数値はこちらを主に採用しています。天破の刻の実質当選確率（1/100.2〜1/81.3）はDMM・一撃の両方で一致していることを確認済みです。また、AT初当たり確率は一撃側にのみ設定1〜6の完全なテーブルが掲載されていたため、そちらを採用しました。

## データについて

以下は両サイトで見つけたものの、本ツールには採用しなかった要素です。

- **筐体ランプA（規定あべし・モード示唆ランプ）**：「黄緑点灯＝通常B以上示唆、否定で設定2以上濃厚」のように、示唆内容が後の展開（規定ゲーム数超えの有無）で確定するかどうかに依存する条件付き情報のため、単純なタップ集計では正しく表現できず除外しました。
- **内部状態移行率（低確/通常/高確）**：設定差はあるものの、プレイヤーが現在の内部状態を確実に把握できないため、確度の高い(n, k)データとして入力させることができず除外しました。
- **闘神レベル・神拳勝舞の勝率・拳王強襲・特闘/極闘のループ率など**：AT・上位AT中の演出内容や継続抽選に関する要素で、いずれも全設定共通または「設定」ではなく獲得枚数に関わる抽選のため対象外としました。
- **サミートロフィーの色別×消化ゲーム数別の詳細出現率表**：色ごとに「設定n以上濃厚」という確定情報がDMM・一撃の双方で明記されていたため、②のハード確定チップとして採用し、複雑なゲーム数レンジ別の出現率テーブル自体は数値チャンネル化していません。
