# スマスロ とある科学の超電磁砲2 設定判別ツール

「とある科学の超電磁砲2」（レールガンパチスロ）の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4892#anc-point)（2026/09/06更新）に掲載されている判別要素を、DMMの分類順（AT終了画面→藤丸コイン→獲得枚数表示）のまま反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。

※本サイトには同じ「とある」シリーズの別機種として[「とある魔術の禁書目録2」設定判別ツール](../2026-09-08-toaru-index2/)も存在しますが、本ツールは「とある科学の超電磁砲2（レールガン）」専用の別ツールです。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-toaru-railgun2/

## 機能

- **数値データ**（①）: 7つの独立した二項尤度チャンネルを、共有する母数ごとに5つの見出しにまとめて入力可能
  - AT初当り・CZ・上位CZ当選率（総G数ベース、共通の「総G数」入力欄を使用）
    - AT初当り確率（設定1: 1/317.8〜設定6: 1/235.3、一撃調べ）
    - CZ（GIRLS JUDGE）確率（設定1: 1/179.99〜設定6: 1/145.25）
    - 上位CZ「婚后光子と知っての挑戦ですの」確率（設定1: 1/7456.18〜設定6: 1/2586.86。設定1と6で約3倍の差がある目玉チャンネル）
  - 通常時のエピソードボーナス直撃率（通常時の超電磁砲コイン揃い回数を母数、設定1: 約1/39680〜設定6: 約1/10168）
  - AT終了後の高確移行率（AT終了回数を母数、設定1: 12.50%〜設定6: 18.75%）
  - AT開始時のステージ振り分け（AT開始回数を母数としたBUNNY DANCE選択率、設定1: 1.17%〜設定6: 3.13%）
  - 通常滞在時のチェリー成立時・高確移行率（通常滞在時のチェリー成立回数を母数、設定1: 33.20%〜設定6: 40.23%）
- **判別要素**（②）: DMMぱちタウン・一撃の両方に掲載された全4カテゴリ・31種類の演出を、DMMの分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - AT終了画面（8種）: 大切な友達B（偶数示唆）・御坂美琴＆食蜂操祈（枠なし・高設定示唆[弱]）・御坂美琴＆御坂妹（高設定示唆[強]）に加え、大切な友達D（赤枠・2以上濃厚）〜御坂美琴ウエディング（虹枠・6濃厚）までの濃厚4段階
  - 藤丸コイン（5種）: 銅（2以上濃厚）／銀（3以上濃厚）／金（4以上濃厚）／DANGER（5以上濃厚）／虹（6濃厚）— 1geki.jp側のみ全色の内訳が掲載されていたため、そちらを採用
  - 獲得枚数表示カード（7種）: 美琴＆食蜂（高設定示唆[弱]）・私服／テニス（高設定示唆[中]）・4人（高設定示唆[強]）に加え、水着（2以上濃厚）・お風呂（偶数濃厚）・一方通行アクセラレータ（4以上濃厚）
  - 獲得枚数表示：語呂合わせ・特定枚数（11種）: 087枚（おはな）〜1666枚まで、すべて金文字の「〜濃厚」
  - 金文字表示の「〜濃厚」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と［弱/中/強］の強さに応じて参考程度の重みだけを加える
- タップ式のカウンターUI（コンパクトな一覧チップ表示でページを短く保つ）
- 数値データとカウント結果を組み合わせて、現在の有力候補と最有力設定をリアルタイム表示
- 広告枠（`.ad-slot`）を3か所設置：ヘッダー直下（728×90）、判別要素と結果の間（300×250）、フッター上（728×90）。今はプレースホルダー表示のみ（詳細はリポジトリルートのREADME「広告の設置について」を参照）

## 一撃（1geki.jp）とのクロスチェック（2026-09-10）

[一撃「レールガン2（スロット）」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_railgun2/0/)（2026/01/16更新）を確認したところ、CZ/上位CZ確率・通常時のエピソードボーナス直撃確率・AT終了時の状態移行抽選（高確移行率）・通常滞在時のチェリー/スイカ成立時の状態移行率・AT終了画面（設定示唆分）・獲得枚数表示カード・獲得枚数表示の語呂合わせ枚数は、いずれもDMMぱちタウン側の数値・示唆内容と完全に一致していた。

AT初当り確率（設定1: 1/317.8〜設定6: 1/235.3）はDMMぱちタウン側には掲載されておらず、一撃側にのみ掲載されている独立した数値テーブルだったため、コード中のコメントに「一撃調べ」と明記した上でそのまま採用している。

藤丸コインについては、DMM側は「藤丸コイン出現時は設定2以上濃厚となる」という銅相当の1行説明のみだったのに対し、一撃側には銅／銀／金／DANGER／虹の5色それぞれの示唆内容が完全なテーブルで掲載されていたため、より詳細な一撃側のテーブルをそのまま採用した。

## データについて

以下は両サイトを確認したが、設定差ではなく別の情報、または実戦上判別が困難なため採用しなかった項目：

- **大切な友達C（AT終了画面・白枠）「Eternal Party濃厚」**: これは引き戻し特化ゾーン「Eternal Party」への突入を示す演出であり、機種設定そのものの示唆ではないため判別要素の対象外とした
- **モードごとのCZ天井ゲーム数振り分け（199G/299G/399G）**: モードA・B滞在時にのみ設定差が存在するテーブルだが、モードC〜E滞在時は全設定共通になる仕様で、かつプレイヤーが現在どのモードに滞在しているかを外部から正確に判別する手段がないため、誤ったチャンネルとして扱ってしまうリスクを避けるために対象外とした
- **高確準備滞在時のチェリー成立時・高確移行率、およびスイカ契機の内部状態移行率**: 通常滞在時のチェリー契機の移行率と近い性質の重複チャンネルであり、プレイヤーが「通常滞在」「高確準備滞在」をリアルタイムに正確に区別して記録するのは実戦上ほぼ不可能なため、代表チャンネルとして通常滞在時のチェリー契機のみを採用し、残りは対象外とした
- **AT開始時のステージ振り分け（駆動鎧／ドッペルゲンガー）**: バニーダンスの選択率が設定1〜6で最も明確な倍率差（約2.7倍）を持つ代表チャンネルであるため採用し、駆動鎧・ドッペルゲンガーの振り分け（設定差が相対的に小さい）は重複を避けるため対象外とした
- **超電磁砲コイン準備状態の当選率・変換当選率テーブル**: 内部的な前段階の抽選値であり、超電磁砲コイン揃いという最終結果に既に反映されているため、二重計上を避ける目的で個別チャンネルとしては対象外とした

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算: 各数値チャンネルの二項分布 `P(k|n,p)` の対数尤度を合算し、示唆要素は出現回数（上限3回でキャップ）×tier別の重み（弱0.2／通常0.35／強0.5）を加算。その後ソフトマックス的に正規化（一様事前分布を仮定）
- 実装パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲：CSS（`:root`〜`</style>`）とHTML骨格・フィードバックウィジェットをそのまま流用し、`numericInputs`配列（id列挙順）→イベントリスナー（`numericInputs.forEach((el) => el.addEventListener('input', render))`）→`render()`内の分割代入、の3点の並び順を完全一致させて配線漏れを防止
- 空欄フィールドの安全対策は[スマスロ モンスターハンターライズ 設定判別ツール](../2026-09-07-monhun-rise/)の`render()`パターンを踏襲：`parseField()`ヘルパーが空欄を`null`として返し、AT初当り・CZ・上位CZ確率の3チャンネルは共通の「総G数」を母数としつつ各チャンネルの`k`フィールドが`null`かどうかを個別に判定してから尤度計算に加える（「総G数は入力したが上位CZ当選回数は空欄」という状態を「0回」と誤読しないようにするため）。残り4つの母数専有チャンネル（コイン揃い回数・AT終了回数・AT開始回数・チェリー成立回数）は、母数が入力されていれば`k`は未入力時に0として扱う単純なnullish-orパターンを使用
