# スマスロ東京喰種 設定判別ツール

「L 東京喰種」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4742#anc-point)（2026/09/06更新）に掲載されている判別要素をそのままの分類（終了画面系／通常時演出／エンディング／獲得枚数表示）で反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。

## 一撃（1geki.jp）とのクロスチェック（2026-09-07、数値データ細分化を2026-09-07に追記）

[一撃「東京グール」設定差・設定判別・終了画面](https://1geki.jp/slot/l_tokyoghoul/0/)（2026/08/03更新）を確認したところ、掲載されている数値・示唆内容はDMMぱちタウンの内容と完全に一致していた。

前回チェック時は「AT引き戻し当選率」の設定2の値が1geki側で欠落していたため未採用としていたが、DMMぱちタウン側のページが2026/08/12に「裏AT当選率（直行）」を更新した際、**AT引き戻し当選率が設定1〜6まで完全なテーブルとして掲載されている**ことを確認したため、今回あらためて採用した（設定1: 7.81% 〜 設定6: 15.23%、うち設定2は設定1と同値の7.81%）。

さらにユーザーからのフィードバックを受け、以下の点を修正・追加した：
- 裏AT関連の「直行／100G以内／200G以内」の3チャンネルが同じ`field-group-label`の下にまとめられていて区別しにくかったため、**それぞれ独立した見出し**を付けて明確に分離した
- 「AT引き戻し当選率」を裏AT関連とは別の**独立した数値チャンネル**として追加（裏ATとAT引き戻しは全く別の抽選）
- DMMぱちタウンに掲載されているものの未使用だった数値テーブルを追加採用：
  - **エピソードボーナス当選率**（CZ・エピソードボーナスの3つ目のチャンネル、これまでレミニセンス・大喰いの利世のみだった）
  - **下段リプレイ確率**（赫眼状態への移行契機。CZ確率とは独立した小役）
  - **AT直撃当選確率**（エピソードボーナス非経由でのAT当選）
  - **弱チェリー契機のCZ当選率**（通常滞在時／高確滞在時、それぞれ独立入力）
  - **規定ゲーム数（100G以内）によるCZ当選率**（全モード平均値）

## 機能

- **数値データ**（①）: CZ・エピソードボーナス（総G数・レミニセンス・大喰いの利世・エピソードボーナス）、下段リプレイ確率、AT直撃当選確率、弱チェリー契機のCZ当選率（通常／高確）、規定ゲーム数（100G以内）によるCZ当選率、裏AT関連（直行／100G以内／200G以内をそれぞれ独立した見出しで分離）、AT引き戻し当選率（裏ATとは別の独立したチャンネル）——全9系統をそれぞれ独立した二項尤度チャンネルとして入力可能
- **判別要素**（②）: AT終了画面、CZ終了画面のエンドカード、ナミちゃんトロフィー、月山招待状、エンディングのレア役カード、獲得枚数表示のすべての要素（計38種類）を、DMMぱちタウンの分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 金文字表示の「〜濃厚」「〜否定」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と［弱/強］の強さに応じて参考程度の重みだけを加える
- タップ式のカウンターUI（コンパクトな一覧チップ表示でページを短く保つ）
- 数値データとカウント結果を組み合わせて、現在の有力候補と最有力設定をリアルタイム表示
- 広告枠（`.ad-slot`）を3か所設置：ヘッダー直下（728×90）、判別要素と結果の間（300×250）、フッター上（728×90）。今はプレースホルダー表示のみ（詳細はリポジトリルートのREADME「広告の設置について」を参照）

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算: CZ・裏AT関連それぞれの二項分布 `P(k|n,p)` の対数尤度を合算し、示唆要素は出現回数（上限3回でキャップ）×tier別の重み（弱0.2／通常0.35／強0.5）を加算。その後ソフトマックス的に正規化（一様事前分布を仮定）
- 判別要素は単一のデータ配列（`ITEMS`）で定義し、各項目の`kind`（hard/soft）と`cat`フィールドで確定/示唆の別とDMMの分類ラベルを保持。チップUIは`cat`が変わるタイミングで自動的にラベル＋新しい行を生成する — 今後の機種でも同じパターンを流用できる
- 裏AT関連の3つの確率テーブル（直行／ゲーム数契機100G／200G）はそれぞれ独立した二項分布として扱っており、厳密には母集団が一部重複する可能性がある（100G以内の当選は200G以内にも含まれるなど）。実用上の簡易計算として割り切っている
