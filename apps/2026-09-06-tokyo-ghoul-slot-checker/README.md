# スマスロ東京喰種 設定判別ツール

「L 東京喰種」の設定判別を助ける計算ツール。公開されている設定差データ（[DMMぱちタウン](https://p-town.dmm.com/specials/4038)、2026/09/01更新）をもとに、実戦データと示唆演出のチェックから設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-06-tokyo-ghoul-slot-checker/

## 機能

- 総G数・レミニセンス当選回数・大喰いの利世当選回数を入力すると、二項尤度に基づくベイズ推定で設定1〜6の期待度をバーチャートで表示
- CZ終了画面のエンドカード、AT終了画面、月山招待状、獲得枚数表示、エンディングカードなど、記事に掲載された全ての示唆演出をチェックリスト化。チェックすると矛盾する設定を候補から自動的に除外
- 数値データと示唆チェックを組み合わせて、現在の有力候補と最有力設定をリアルタイム表示

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算: 各設定の二項分布 `P(k|n,p)` の対数尤度を合算し、ソフトマックス的に正規化（一様事前分布を仮定）
