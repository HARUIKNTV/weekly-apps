# スマスロ東京喰種 設定判別ツール

「L 東京喰種」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4742#anc-point)（2026/09/05更新）に掲載されている判別要素をそのままの分類（終了画面系／通常時演出／エンディング／獲得枚数表示）で反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-06-tokyo-ghoul-slot-checker/

## 機能

- **数値データ**（①）: CZ・エピソードボーナス（総G数・レミニセンス・大喰いの利世）に加え、裏AT関連（有馬J非経由のAT当選回数と裏AT直行回数、100G/200G以内のゲーム数契機AT当選回数と裏AT当選回数）も入力可能。二項尤度に基づくベイズ推定で設定1〜6の期待度をバーチャートで表示
- **判別要素**（②）: AT終了画面、CZ終了画面のエンドカード、ナミちゃんトロフィー、月山招待状、エンディングのレア役カード、獲得枚数表示のすべての要素（計38種類）を、DMMぱちタウンの分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 金文字表示の「〜濃厚」「〜否定」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と［弱/強］の強さに応じて参考程度の重みだけを加える
- タップ式のカウンターUI（コンパクトな一覧チップ表示でページを短く保つ）
- 数値データとカウント結果を組み合わせて、現在の有力候補と最有力設定をリアルタイム表示

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算: CZ・裏AT関連それぞれの二項分布 `P(k|n,p)` の対数尤度を合算し、示唆要素は出現回数（上限3回でキャップ）×tier別の重み（弱0.2／通常0.35／強0.5）を加算。その後ソフトマックス的に正規化（一様事前分布を仮定）
- 判別要素は単一のデータ配列（`ITEMS`）で定義し、各項目の`kind`（hard/soft）と`cat`フィールドで確定/示唆の別とDMMの分類ラベルを保持。チップUIは`cat`が変わるタイミングで自動的にラベル＋新しい行を生成する — 今後の機種でも同じパターンを流用できる
- 裏AT関連の3つの確率テーブル（直行／ゲーム数契機100G／200G）はそれぞれ独立した二項分布として扱っており、厳密には母集団が一部重複する可能性がある（100G以内の当選は200G以内にも含まれるなど）。実用上の簡易計算として割り切っている
