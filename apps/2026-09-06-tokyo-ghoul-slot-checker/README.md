# スマスロ東京喰種 設定判別ツール

「L 東京喰種」の設定判別を助ける計算ツール。公開されている設定差データ（[DMMぱちタウン](https://p-town.dmm.com/specials/4038)、2026/09/01更新）をもとに、実戦データと示唆演出の出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-06-tokyo-ghoul-slot-checker/

## 機能

- 総G数・レミニセンス当選回数・大喰いの利世当選回数を入力すると、二項尤度に基づくベイズ推定で設定1〜6の期待度をバーチャートで表示
- **濃厚・否定要素**（エンドカード、AT終了画面、招待状、獲得枚数表示、エンディングカードのうち「〜濃厚」「〜否定」に該当するもの）はタップ式カウンターで記録。1回でも出現すれば、矛盾する設定を候補から確実に除外
- **示唆要素**（「奇数設定示唆」「偶数設定示唆」など、確定情報ではないもの）は別枠のカウンターで記録し、出現回数に応じてハード除外はせず参考程度の重みだけを加える（あくまで可能性の目安であることを明示）
- 全て数値入力ではなくタップ式のカウンターUI（コンパクトな一覧チップ表示でページを短く保つ）
- 数値データとカウント結果を組み合わせて、現在の有力候補と最有力設定をリアルタイム表示

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算: 各設定の二項分布 `P(k|n,p)` の対数尤度を合算し、示唆要素は出現回数（上限3回でキャップ）×固定の小さな重み（0.35）を加算。その後ソフトマックス的に正規化（一様事前分布を仮定）
- 濃厚・否定要素と示唆要素はデータ配列（`HARD_ITEMS`/`SOFT_ITEMS`）で定義し、チップUIを動的生成 — 今後の機種でも同じパターンを流用できる
