# スマスロ東京喰種 設定判別ツール

「L 東京喰種」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4742#anc-point)（2026/09/05更新）に掲載されている判別要素をそのままの分類（終了画面系／通常時演出／エンディング／獲得枚数表示）で反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-06-tokyo-ghoul-slot-checker/

## 機能

- 総G数・レミニセンス当選回数・大喰いの利世当選回数を入力すると、二項尤度に基づくベイズ推定で設定1〜6の期待度をバーチャートで表示
- **濃厚・否定要素**（AT終了画面、CZ終了画面のエンドカード、ナミちゃんトロフィー、月山招待状、エンディングのレア役カード、獲得枚数表示のうち「〜濃厚」「〜否定」に該当するもの、計22種類）はタップ式カウンターで記録。1回でも出現すれば、矛盾する設定を候補から確実に除外
- **示唆要素**（「奇数/偶数設定示唆」「高設定示唆［弱/強］」など、確定情報ではないもの、計11種類）は別枠のカウンターで記録し、出現回数と［弱/強］の強さに応じてハード除外はせず参考程度の重みだけを加える
- DMMぱちタウンの分類（AT終了画面／CZ終了画面のエンドカード／ナミちゃんトロフィー／月山招待状／エンディングのレア役カード／獲得枚数表示）をそのままカテゴリラベルとして保持し、通常時・CZ時・AT時の演出を混同しない
- タップ式のカウンターUI（コンパクトな一覧チップ表示でページを短く保つ）
- 数値データとカウント結果を組み合わせて、現在の有力候補と最有力設定をリアルタイム表示

## データソースについて

以前は特集記事（[スマスロ東京喰種（グール）の設定差はこれを見ればOK！](https://p-town.dmm.com/specials/4038)）のみを参照していたが、2026-09-06にユーザーの指示で機種ページ本体の「設定判別・推測ポイント」セクションに切り替え。特集記事になかった「ナミちゃんトロフィー」「AT終了画面の追加示唆（笛口雛実＆笛口リョーコ、四方蓮示＆イトリ＆ウタ）」「エンディングのレア役カード（白・青・赤の色別示唆）」を追加で反映した。

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算: 各設定の二項分布 `P(k|n,p)` の対数尤度を合算し、示唆要素は出現回数（上限3回でキャップ）×tier別の重み（弱0.2／通常0.35／強0.5）を加算。その後ソフトマックス的に正規化（一様事前分布を仮定）
- 濃厚・否定要素と示唆要素はデータ配列（`HARD_ITEMS`/`SOFT_ITEMS`）で定義し、各項目の`cat`フィールドでDMMの分類ラベルを保持。チップUIは`cat`が変わるタイミングで自動的にラベル＋新しい行を生成する — 今後の機種でも同じパターンを流用できる
