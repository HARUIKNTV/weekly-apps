# スマスロ鉄拳6 設定判別ツール

「スマスロ鉄拳6」（山佐、TEKKEN™シリーズ／©Bandai Namco Entertainment Inc.）の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4913#anc-point)（2026/08/27更新）と[一撃「スマスロ鉄拳6」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_tekken6/0/)（2026/08/03更新）の両方を全文確認したうえで、両サイトで数値が一致した完全な設定1〜6テーブルのみを二項尤度チャンネルとして採用し、実戦データと「濃厚」演出（ケロットトロフィー・終了画面）の出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-tekken6/

## 機能

- **数値データ**（①）: 以下8系統をそれぞれ独立した二項尤度チャンネルとして入力可能
  - **AT初当たり確率**（総G数ベース。一撃のみに完全な設定1〜6テーブルが掲載）
  - **ボーナス初当たり確率**（総G数ベース。一撃のみに完全な設定1〜6テーブルが掲載）
  - **CZ確率**（総G数ベース、ロックオンチャレンジ・一八チャレンジ合算。DMM・一撃とも数値が完全一致）
  - **鉄拳RUSH（AT）直撃確率**（総G数ベース、成立役不問。DMM・一撃とも数値が完全一致。分母が非常に大きいため参考程度）
  - **ボーナス直撃当選率（弱チェリー・スイカ・チャンス目契機）**：DMM・一撃とも一致
  - **ボーナス直撃当選率（強チェリー契機）**：弱レア役契機とは母数が異なるため見出しを分離
  - **引き戻しモード移行率**（AT終了時・デビルRUSH終了時、99pt以内の引き戻し抽選）：DMM・一撃とも一致
  - **鉄拳チャンス（赤）選択率**（鉄拳チャンス初当り時に赤タイトルが選ばれる率）：一撃のみに掲載
- **判別要素**（②）: 「鉄拳チャンス中のAT中BB終了画面」（赤背景1種）、「終了画面：ケロットトロフィー」（銅・銀・金・ケロット・虹の5色）——計6種類をタップ式カウンターで記録
  - 金文字表示の「〜濃厚」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 本機はDMM・一撃とも「〜以上濃厚」「〜濃厚」型の演出のみが確認でき、「〜示唆（弱/強）」のような確定情報ではない斜体表示の要素は見当たらなかったため、②には現状ハード要素（金文字）のみを掲載（下記「データについて」参照）
- タップ式のカウンターUI（コンパクトな一覧チップ表示でページを短く保つ）
- 数値データとカウント結果を組み合わせて、現在の有力候補と最有力設定をリアルタイム表示
- 広告枠（`.ad-slot`）を3か所設置：ヘッダー直下（728×90）、判別要素と結果の間（300×250）、フッター上（728×90）。今はプレースホルダー表示のみ（詳細はリポジトリルートのREADME「広告の設置について」を参照）

## 一撃（1geki.jp）とのクロスチェック

DMMぱちタウンと一撃、両方のページを全文確認したところ、CZ確率・鉄拳RUSH（AT）直撃確率・ボーナス直撃当選率（弱チェリー・スイカ・チャンス目／強チェリー）・引き戻しモード移行率の数値はすべて完全に一致していた。

一撃側にのみ完全な設定1〜6テーブルが掲載されていたのが**AT初当たり確率**（設定1: 1/497.0 〜 設定6: 1/358.5）と**ボーナス初当たり確率**（設定1: 1/264.7 〜 設定6: 1/218.5）、および**鉄拳チャンス（赤）選択率**（設定1: 約4% 〜 設定6: 約13%）。DMMぱちタウン側にはこれらの完全な設定別テーブルが掲載されていなかったため、本ツールでは一撃の値を採用した。

判別要素については、DMM・一撃とも「鉄拳チャンス中のAT中BB終了画面で赤背景（一八／平八／一美）が出現すれば設定4以上濃厚」「ケロットトロフィーの色（銅＝設定2以上濃厚〜虹＝設定6濃厚）」の2点で内容が一致していた。一撃側は「濃厚!?」のように「!?」付きの表記だったため、README・ツール双方に「100%確定ではない」旨を明記している。

## データについて

以下は本文を確認したうえで、あえて数値チャンネル・判別要素チップのいずれにも採用しなかった項目とその理由。

- **エピソードボーナス当選率**（初当りビッグ時の赤7BB→エピソードボーナス移行率）：DMM・一撃とも設定1（約2%）・設定6（約13%）のみ判明で、設定2〜5は「調査中」「???」表記のまま。完全な設定1〜6テーブルが揃っていないため未採用。
- **CZモード振り分け（A〜E）**：DMM・一撃とも完全な設定1〜6テーブルが掲載されていたが、5カテゴリの多項分布であり単純な二項尤度チャンネルに落とし込むと選択肢間の相互排他性を壊してしまうため未採用。より単純な合算値である「CZ確率」を代わりに採用した。
- **規定鉄拳ポイント振り分け（ゾーン／モード別テーブル）**：DMM・一撃とも詳細な表が掲載されていたが、内部モード（通常A〜C／天国／デビル／引き戻し／設定変更）ごとの多項分布であり、かつ「モード」の推測情報であって設定そのものの判別要素ではないため対象外とした。
- **CZステージ示唆（BARステージ＝モードC以上濃厚、仁ステージ＝モードD以上濃厚、平八ステージ＝モードE濃厚）**：これらはCZモード（内部状態）の示唆であり、設定との直接の結び付きは確認できなかったため対象外とした。
- **非鉄拳チャンス中のAT中BB終了画面（仁＝鉄拳チャンス期待度50%、一八・平八・一美＝鉄拳チャンス濃厚など）**：1geki.jp側に「鉄拳チャンス突入時の終了画面は設定示唆でないので注意」と明記されており、鉄拳チャンス当選期待度の示唆であって設定判別要素ではないため対象外とした。
- **初当りボーナス終了画面／鉄拳ラッシュ終了画面のモード＆規定鉄拳ポイント示唆**（ラース／シャオユウ／キング＝告知タイプのデフォルト、仁＝規定300pt以内期待度など）：告知タイプの選択やモード・規定ポイントの示唆であり、設定判別要素ではないため対象外とした。
- **ボーナス直撃当選確率（合算値、1/1915.3〜1/899.8）**：弱チェリー・スイカ・チャンス目契機の直撃率（0.4%/1.6%）から導出される合成値で、採用済みの内訳データと重複するため別チャンネルとしては未採用。
- **小役確率（弱チェリー・強チェリー・スイカ・チャンス目・ブースト目など）**：DMM側の表は設定ごとの内訳がなく単一の確率値のみだったため、設定差データとしては利用できず対象外。

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算: 各数値チャンネルの二項分布 `P(k|n,p)` の対数尤度を合算し、ソフトマックス的に正規化（一様事前分布を仮定）。本機は現状「示唆（soft）」要素がないため、`TIER_WEIGHT`／`SOFT_CAP`の重み付け機構はコード上に残しつつ実質未使用
- 判別要素は単一のデータ配列（`ITEMS`）で定義し、各項目の`kind`（hard/soft）と`cat`フィールドで確定/示唆の別と分類ラベルを保持。チップUIは`cat`が変わるタイミングで自動的にラベル＋新しい行を生成する
- 空欄の数値フィールドは「データなし（そのチャンネルを計算に含めない）」を意味し、「0件」とは区別している。`parseField()`が空欄を`null`として返し、各チャンネルの対数尤度計算を自分のフィールドが`null`でないことでゲートする実装は[スマスロ モンスターハンターライズ 設定判別ツール](../2026-09-07-monhun-rise/)の`render()`を踏襲した
- `numericInputs`配列（要素の並び順）→ イベントリスナー（`numericInputs.forEach((el) => el.addEventListener('input', render))`）→ `render()`内の分割代入、の3点の並び順が一致していることを確認済み（[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)で見つかった配線漏れバグと同じ観点でチェック済み）
- ボーナス直撃当選率は「弱チェリー・スイカ・チャンス目契機」「強チェリー契機」で母数（n）が異なるため`field-group-label`を分離した。一方、AT初当たり・ボーナス初当たり・CZ・AT直撃の4チャンネルはいずれも総G数を共通の母数とするため、1つの見出しにまとめている（[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲したパターン）
- CSS・HTMLスケルトン（白／黒／赤のパレット、ヘッダー／広告枠／カード①②③／source／disclaimer／footer構成）は[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)をベースに作成
