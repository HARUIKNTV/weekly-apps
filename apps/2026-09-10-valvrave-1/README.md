# 革命機ヴァルヴレイヴ（初代） 設定判別ツール

「スマスロ パチスロ 革命機ヴァルヴレイヴ」（2022年11月21日導入のSANKYOスマスロ第1弾）の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4244#anc-point)（2026/09/08更新）と[一撃「ヴァルヴレイヴ（スロット）」設定差・設定判別要素まとめ](https://1geki.jp/slot/s_valvrave/0/)（2025/12/09更新）に掲載されている判別要素を反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-valvrave-1/

## 「革命機ヴァルヴレイヴ2」との違い（重要）

本サイトには[「革命機ヴァルヴレイヴ2」の判別ツール](../2026-09-06-valvrave-2/)（DMM機種ID: `4885`、2025年11月04日導入）が既に存在するが、これは**後継機（2代目）**である。本ツールが対象とするのは、それより先に登場した**初代機**「パチスロ 革命機ヴァルヴレイヴ」（DMM機種ID: `4244`、2022年11月21日導入）であり、別機種・別ツールとして新規作成した。

- 初代（本ツール）: DMM機種ID `4244`、設定1〜6の6段階設定、導入日2022/11/21
- ヴァルヴレイヴ2: DMM機種ID `4885`、設定1・2・4・5・6の5段階設定（設定3が存在しない）、導入日2025/11/04

DMMのページタイトルにも「2」が付かないこと、シリーズ一覧ページで初代がヴァルヴレイヴ2の「シリーズ最新機種（後継機）」として案内されていることを確認済み。

## 機能

- **数値データ**（①）: 「ボーナス初当り確率・CZ『共闘Vチャレンジ』出現率」（総G数を共有する2独立チャンネル）と「革命ボーナス当選時の革命ラッシュ（AT）当選率」（革命ボーナス当選回数を分母とする独立チャンネル）を、それぞれ独立した二項尤度チャンネルとして入力可能
- **判別要素**（②）: CZ・ボーナス終了画面（紫枠・赤枠・金枠）、AT終了画面（青背景）、ラウンド開始画面（ビーストハイ・リーゼロッテ）、獲得枚数表示（456/555/666枚OVER）をタップ式カウンターで記録
  - 金文字表示の「〜濃厚」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と強さに応じて参考程度の重みだけを加える
- 空欄の数値入力は「データなし」として扱い、0を入力した場合（確定0回）とは明確に区別（`parseField`ヘルパーで実装）
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用
- サイト共通のフィードバックウィジェット（💬フローティングボタン、FormSubmit.co経由でメール送信）を搭載

## 一撃（1geki.jp）とのクロスチェック

DMMぱちタウンの「設定判別・推測ポイント」には数値テーブルとして「革命ボーナス当選時の革命ラッシュ当選率」（設定1: 約5%〜設定6: 約13%）のみが掲載されていた。一撃のページを確認したところ、DMMには掲載されていない「ボーナス（革命/決戦）初当り確率」（設定1: 1/519〜設定6: 1/490）と「CZ『共闘Vチャレンジ』出現率」（設定1: 1/277〜設定6: 1/258）という2つの数値テーブルが新たに見つかったため、①数値データに追加した。「革命ボーナス当選時の革命ラッシュ当選率」の数値はDMMと一撃で完全に一致していることを確認済み。

一撃には「CZ/ボーナス終了画面の示唆」として枠色別の設定示唆（紫枠①②＝高設定示唆、赤枠①＝設定2以上濃厚、赤枠②＝設定4以上濃厚、金枠＝設定6濃厚）と、それぞれの出現率テーブルが掲載されていた。DMM側は同じ終了画面の一覧を画像でのみ提示しており、文章での設定対応の記載がなかったため、この判別要素については一撃の記載を採用した。DMMの「AT中のラウンド開始画面」「特定獲得枚数表示の示唆」の記載（ビーストハイ＝設定4以上濃厚、リーゼロッテ＝設定6濃厚、456/555/666枚OVER）は一撃の記載と完全に一致していたため、両ソースで裏取りが取れた要素として採用した。

## データについて

以下は見つけたが、理由付きで採用しなかった項目。

- **CZ/ボーナス終了画面「白枠①（2人）／白枠②（3人）／白枠③（4人）」**: 一撃では「基本パターン!?」「奇数示唆!?」「偶数示唆!?」という記載だった。白枠①は判別に寄与しない基本パターン、白枠②③の「奇数/偶数示唆」は本ツールのチップ体系（濃厚＝ハード除外、示唆＝弱/通常/強のtier加重）にうまく当てはまらない特殊な分類であり、かつ出現率テーブルを見ても設定間の差が小さく（例: 白枠①は全設定で約74〜79%と横ばい）、参考情報としての信頼性が低いと判断し未採用とした
- **ハラキリドライブ発生率**: DMM・一撃とも「高設定ほど発生しやすい」という定性的な記載のみで、設定ごとの正確な数値・出現率テーブルが公開されていないため未採用
- **（超）革命ラッシュのセット初期ゲーム数**: 「高設定ほど50G・100Gが選ばれやすい（設定1と6で約3倍差）」という記載のみで、設定ごとの正確な内訳テーブルが公開されていないため未採用
- **通常時のボーナス選択比率（革命ボーナスの選択率優遇）**: 一撃の「その他の設定示唆要素」に記載があったが、設定ごとの数値テーブルがなく定性的な記載のみのため未採用
- **HOLD当選率、パネル振り分け・昇格率、ドルシア軍襲来（バトル）の前兆ゲーム数振り分け、Vストック獲得率、カミツキステージ前兆・滞在ゲーム数期待度など**: いずれもDMMの解析情報セクションに掲載されているが、AT内部の抽選ルート・モード（内部状態）に関する確率であり設定差を示すものではないため対象外

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- この機種は設定1〜6の6段階すべてに公開データが揃っているため、`SETTINGS`オブジェクトキー方式（一部設定が欠落する機種向けのパターン）は使用せず、標準の6要素配列（`[設定1, 設定2, ..., 設定6]`）で確率テーブルを保持している
- 空欄と0を区別する`parseField`ヘルパー、チップUI・尤度計算の基本パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲し、複数設定が欠落する機種向けの`SETTINGS`配列パターンは[革命機ヴァルヴレイヴ2 設定判別ツール](../2026-09-06-valvrave-2/)を参考にした（本機種では不要と判断し未使用）
