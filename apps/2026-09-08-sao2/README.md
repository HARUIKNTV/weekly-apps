# スロット ソードアート・オンラインⅡ 設定判別ツール

「スロット ソードアート・オンラインⅡ」（SAO2）の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/5025#anc-point)（2026/09/09更新）と[一撃「SAO2」設定差・設定示唆まとめ](https://1geki.jp/slot/l_sao2/0/)（2026/09/04更新）の両方を読み込み、両サイトに掲載されている設定1〜6テーブルと示唆演出を反映して構築した。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-08-sao2/

## 機能

- **数値データ**（①）: 以下7つの見出し（計10系統の独立した二項尤度チャンネル）をそれぞれ入力可能
  - AT初当り確率・スコードロンバトル［CZ］初当り確率・GGOモード「詩乃」契機のAT直撃確率・確定CZ（THE ENDモード）出現率 — 総G数ベースの4チャンネルを共有の「総G数」入力欄でまとめて算出
  - AT初当り時のステージ振り分け（荒野選択率。奇数設定60%／偶数設定40%、50G以内の引き戻し含む・高確率スタート除く）
  - スイカ成立時のシューティングチャージ突入率（低確滞在時）
  - 強チェリー成立時のスコードロンバトル［CZ］突入抽選（低確滞在時／高確滞在時をそれぞれ独立入力）
  - 強チャンス目成立時の確定CZ（THE ENDモード）抽選
  - CZ失敗時のアイテム獲得抽選
- **判別要素**（②）: AT終了画面（9種）、コパンダトロフィー（5種）、エンディング／マザーズ・ロザリオのミニキャラ（8種）、スナイパーチャンス（AT中、1種）の計4カテゴリ・23種類の演出を、DMMぱちタウン／一撃の分類順のままカテゴリラベル付きでタップ式カウンターで記録
  - 金文字表示の「〜濃厚」は1回でも出現すれば矛盾する設定を候補から確実に除外（計11種）
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と［弱/通常/強］の強さに応じて参考程度の重みだけを加える（計12種）
- タップ式のカウンターUI（コンパクトな一覧チップ表示でページを短く保つ）
- 数値データとカウント結果を組み合わせて、現在の有力候補と最有力設定をリアルタイム表示
- 広告枠（`.ad-slot`）を3か所設置：ヘッダー直下（728×90）、判別要素と結果の間（300×250）、フッター上（728×90）。今はプレースホルダー表示のみ（詳細はリポジトリルートのREADME「広告の設置について」を参照）

## 一撃（1geki.jp）とのクロスチェック

DMMぱちタウンと一撃の両方を全文読み比べた結果、重複する数値テーブル（スコードロンバトル［CZ］初当り確率、スイカのシューティングチャージ突入率、強チェリー成立時のCZ突入抽選、確定CZ突入抽選・出現率、GGOモード「詩乃」契機のAT直撃確率、CZ失敗時のアイテム獲得率、AT終了画面・コパンダトロフィー・エンディング/マザーズ・ロザリオのミニキャラ示唆）はすべて完全に一致していた。

**AT初当り確率**（設定1: 1/386.2〜設定6: 1/269.6）と**AT初当り時のステージ振り分け**（荒野選択率）は一撃側にのみ設定1〜6の完全なテーブルとして掲載されていたため、そのまま採用した（DMM側では該当テーブルの掲載を確認できなかった）。

## データについて

以下は両サイトを確認したが、理由があって採用しなかった項目：

- **強チャンス目Bの出現確率**: 設定1（1/1057.0）のみが判明しており、設定2〜6は両サイトとも「???」で不明。誤った補間を避けるため未採用とした。
- **CZ失敗時の「曠野の決闘」発生抽選**: 設定1（1/128.0）と設定6（1/64.0）の両端しか具体的な数値が掲載されておらず、設定2〜5は「調査中」（DMM）／「???」（一撃）と欠落している。中間設定の値が不明なため未採用とした。
- **GGOモード移行率**: 「設定1：約20%」という記載のみで、設定2〜6の具体的な数値を伴う完全なテーブルが存在しないため未採用とした。
- **スナイパーチャンス1・2戦目でのデス・ガン出現率**: 「設定5は選択されやすい」という推測表現のみで、設定別の具体的な数値テーブルが存在しない。そのため数値チャンネルではなく、②の判別要素に示唆［弱］・対象設定5のみのチップとして反映した。
- **AT終了画面のPUSHボイス**（モード示唆）: DMM・一撃とも「現状では設定示唆ではないと推察される」と明記されており、モードアップ系の示唆にとどまるため対象外とした。
- **通常時のステージ示唆**（酒場・公園・SBCグロッケン・Sterben等）、**GGOモードのアイテム示唆**（キリト＝光剣、詩乃＝アミュスフィア等）、**演出法則各種**（バレットサークルランプ点滅、裏ボタン、カスタム機能、履歴画面のモード示唆等）: いずれも高確率状態・前兆・GGOモード・CZ/AT中の抽選内容を示唆するものであり、隠し設定そのものを示唆する内容ではないため対象外とした。

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算: 各数値チャンネルの二項分布 `P(k|n,p)` の対数尤度を合算し、示唆要素は出現回数（上限3回でキャップ）×tier別の重み（弱0.2／通常0.35／強0.5）を加算。その後ソフトマックス的に正規化（一様事前分布を仮定）
- 実装パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲：`numericInputs`配列（id列挙順）→イベントリスナー（`numericInputs.forEach((el) => el.addEventListener('input', render))`）→`render()`内の分割代入、の3点の並び順を完全一致させて配線漏れを防止
- 判別要素は単一のデータ配列（`ITEMS`）で定義し、各項目の`kind`（hard/soft）と`cat`フィールドで確定/示唆の別とDMM・一撃の分類ラベルを保持。チップUIは`cat`が変わるタイミングで自動的にラベル＋新しい行を生成する
- 「AT初当り確率」「CZ初当り確率」「GGOモード『詩乃』契機のAT直撃確率」「確定CZ（THE ENDモード）出現率」の4チャンネルはすべて母数が同じ「総G数」のため、`totalG`の入力欄は1つだけ用意し、各`field-group-label`の見出しでグルーピングして重複入力を避けた（東京喰種・いざ番長ツールと同じパターン）
- 各数値チャンネルは厳密には観測対象が一部重複する可能性がある（例: 強チェリー成立時のCZ突入抽選と確定CZ抽選は共に「強チャンス目/強チェリー」絡みの排反しない事象群）が、実用上の簡易計算として各チャンネルを独立とみなして割り切っている
