# スマスロ「彼女、お借りします」設定判別ツール

SANKYOのスマスロ「Lパチスロ 彼女、お借りします」（2026年9月7日導入）向けの設定判別ファンメイド計算機です。[DMMぱちタウン「Lパチスロ 彼女、お借りします」設定判別・推測ポイント](https://p-town.dmm.com/machines/5065#anc-point)（2026/09/09更新）を主な情報源とし、CZ出現率・ボーナス初当り確率の数値データと、ボーナス終了画面の枠色・REG中のコスプレ人数示唆の出現回数を入力すると、二項対数尤度＋softmaxで設定1〜6の期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-09-kanojo-okarishimasu/

## 機能

- **数値データ入力**: 総G数・CZ当選回数（レンカノチャレンジ／妄想DTチャレンジ合算）・ボーナス当選回数（初当り）を入力すると、二項対数尤度で各設定の当てはまりを計算。空欄の項目は「データなし」として扱われ、計算から除外されます（0回として扱われることはありません）。
- **判別要素チップ**: ボーナス終了画面の枠色（白枠①・白枠②・赤枠・紫枠・銀枠・金枠）とREG中のキャラ紹介コスプレ人数シナリオ（コス1〜4人）をタップしてカウント。金文字の「濃厚/否定」表記の要素は候補設定を確定・除外し、斜体の「示唆」要素はあくまで参考程度の重みを加えるのみです。
- **結果表示**: 設定1〜6ごとの期待度をバーグラフで表示し、除外された設定は「除外」と明示します。

## 1geki.jpとのクロスチェックについて

[一撃「かのかり（スマスロ/スロット）」設定差・終了画面](https://1geki.jp/slot/l_kanokari/0/)（2026/08/27更新）も参照し、CZ出現率（1/172〜1/149）はDMMぱちタウンと完全に一致することを確認済みです。ボーナス初当り確率（1/269〜1/226）は1geki.jpのみに設定1〜6の完全なテーブルが掲載されていたため、そちらを採用しました（DMM側は機種概要欄に「機械割97.7%〜114.9%」という範囲表記のみで、設定別の内訳は掲載されていませんでした）。この2チャンネルはいずれも総G数を分母とするため、フィールドグループの見出しを共有しています。

## データについて

本機種は2026年9月7日導入の新台で、取材開始からまだ2日しか経過していないため、公開されている設定差データは非常に少なめです。見つかったが採用しなかった要素は以下の通りです。

- **エンディング中のレア役成立時PUSHボタンボイス**: DMMぱちタウンに「詳細は調査中だ」と明記されており、設定との対応関係が未公開のため除外しました。
- **小役変換発生率・変換高確率の内部状態、規定ゲーム数によるCZ/ポイント高確移行、通常モード（モード1〜3）の分布**: いずれも設定差ではなく内部状態・モードに関する記載のみで、設定1〜6別の数値が示されていないため除外しました。
- **天井・ゾーン・ヤメ時**: 天井条件（REG後800G／BIG後1000G、設定変更後600G）はボーナス種別のみに依存し、設定による差異の記載がなかったため除外しました。
- **REG中の1G恋当選率（トータル約5%）・ななかりドリーム終了時の+100G上乗せ抽選**: 契機役別のデータはあるものの、設定別の内訳が公開されていないため除外しました。
- **エンディング枠なし（デフォルト）画面・シナリオ「すべてデフォルト」**: いずれも「示唆なし」の基準状態であり、独立したチップとしてカウントする意味がないため除外しました（他の枠色・コスプレ人数が出なかった場合の既定値として扱われます）。

このため、本ツールの判別要素は数値チャンネル2つ（CZ出現率・ボーナス初当り確率）と判別要素チップ10個（2カテゴリ）にとどまります。導入から日が浅く採用可能なデータが薄いことをご了承のうえご利用ください。今後DMMぱちタウン・一撃で情報が追加され次第、随時アップデートを検討します。

## 技術メモ

本ツールは `apps/2026-09-06-tokyo-ghoul-slot-checker/` の実装パターン（白/黒/赤パレットのCSS、二項対数尤度＋softmaxによる設定推定、`parseField`によるブランクフィールドの安全な扱い、タップ式カウンターチップ）をそのまま踏襲して構築しています。ブランクフィールド処理（`parseField`が空欄を`null`として返し、各チャンネルが自分自身のフィールドの非nullを条件にlog尤度を加算するパターン）は `apps/2026-09-07-monhun-rise/` の実装を参考にしました。
