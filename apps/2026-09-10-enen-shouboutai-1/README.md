## 機能

- **数値データ**（①）: 1geki.jpの当選率まとめ表（初当り・ボーナス・炎炎ループ、総G数ベース）とDMMぱちタウンの契機別ボーナス当選率（十字目変換／強チェリー）を、それぞれ独立した二項尤度チャンネルとして入力可能
- **判別要素**（②）: 炎炎ボーナス終了画面・REG終了画面（パターンA〜E）、アドラバースト炎炎JAC開始時のキャラ紹介、REG中のキャラ紹介シナリオを、DMMぱちタウンの分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 「〜濃厚」「〜否定」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と強さに応じて参考程度の重みだけを加える
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用

## 一撃（1geki.jp）とのクロスチェック

[一撃「炎炎（スマスロ）」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_ennenn/0/)（2025/12/09更新）は「当選率関連まとめ」として初当り・ボーナス・炎炎ループの3種の確率表のみを掲載しており、DMMぱちタウン側にはこの数値テーブルが存在しなかったため、①数値データの主要チャンネルとして採用した。判別要素（チップ）側で1geki.jp独自に新規追加できるものはなかった（DMMぱちタウンの「設定判別・推測ポイント」にすべて掲載済み）。

## データについて（設定3が存在しない5段階設定）

DMMぱちタウン・1geki.jpの両サイトとも、本機種の**すべての設定別数値テーブルで設定3の行が存在しない**（設定1・2・4・5・6のみ掲載）。これは一部の表だけでなく、当選率まとめ表・アドラバースト出現確率・キャラ選択率など確認できたテーブル全てに共通する、両サイトに一貫した仕様であることを確認した。

設定3のデータはどちらのサイトにも一切公開されていないため、本ツールでは設定3の値を補間・推定することはせず、`SETTINGS = [1, 2, 4, 5, 6]`として設定3を候補空間から完全に除外している（[革命機ヴァルヴレイヴ2](../2026-09-06-valvrave-2/)・[サンダーvロード](../2026-09-10-thunder-v/)と同じパターン）。数値チャンネルとして採用した5テーブル（初当り・ボーナス・炎炎ループ・十字目変換契機ボーナス当選率・強チェリー契機ボーナス当選率）も、確率テーブルをオブジェクト（`{1: ..., 2: ..., 4: ..., 5: ..., 6: ...}`）で持たせることで設定3キーを一切含まない形にしている。結果表示（③）も設定1・2・4・5・6の5本のバーのみを表示し、設定3は表示されない。

## 見つかったが不採用とした要素（理由付き）

- **小役確率（チャンス目1/81・強チェリー1/728・十字リプレイ1/4369、いずれも「設定差あり」表記）**: DMMぱちタウンの「小役確率」表は全設定共通の平均値のみを掲載しており、設定別の内訳は非掲載。誤った補間を避けるため数値チャンネル化は見送った。
- **十字目変換契機のボーナス当選率のうち十字リプレイ列**: 同じ「ボーナス当選率」表内で十字目変換・強チェリー列は設定ごとに異なる値が並ぶ一方、十字リプレイ列は設定1の79%のみが掲載され他設定は空欄（＝全設定共通値であることを示す表記）だった。設定差がないため数値チャンネルとして採用する意味がなく、不採用とした。
- **設定変更判別（88G付近の前兆パターン）**: 「設定据え置きor朝イチC」「設定変更濃厚」という判別要素だが、これは据え置き/変更の判別であり、本ツールが扱う「現在の設定1〜6を推測する」問題とは異なる種類の情報のため対象外とした。
- **モード＆天井示唆画面（119／シンラ後ろ姿／ヘルメット）**: 天国モードや天井ゲーム数を示唆する画面であり、設定そのものではなく内部モード・天井到達状況を示唆する情報のため対象外とした。
- **アドラバースト終了画面の色（赤背景でストックあり濃厚）**: アドラバーストの残りストック数を示唆する要素であり、設定を示唆するものではないため対象外とした。
- **オウビ・紅丸・アイリス（炎炎JACキャラ）の「設定n以上」表記**: DMMぱちタウンの表記は「設定2以上」「設定4以上」「設定5以上」であり、他の「〜濃厚」表記と異なり「濃厚」の文字が付いていない。ただし同ページのキャラ選択率テーブルでは対象設定未満において出現率が明確に0%（「－」表記）となっており、この実測裏付けをもって確定的な閾値情報と判断し、本ツールでは「以上濃厚」と同様にハード除外（`type: 'only'`）として扱った。
- **REG中のキャラ紹介シナリオにおけるまもるくんの出現順否定**: シナリオ詳細表（アイリスA〜D）を確認したところ、まもるくんの出現位置による設定否定は「アイリスA:設定1否定」〜「アイリスD:設定5否定」というシナリオ単位のチップと完全に一致（重複する情報）していたため、別チップとしては追加せず、シナリオ単位のチップのみを採用し二重計上を避けた。

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 設定空間を`SETTINGS`配列（`[1, 2, 4, 5, 6]`）で保持し、確率テーブルもオブジェクト（`{1: ..., 2: ..., 4: ..., 5: ..., 6: ...}`）で持たせることで、設定3の値を一切捏造せずに5段階設定の機種に対応する形に一般化（[革命機ヴァルヴレイヴ2](../2026-09-06-valvrave-2/)と同じパターン）
- CSS・HTML骨格・チップUI・尤度計算・空欄フィールドの`null`安全処理（`parseField`）の実装パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲
