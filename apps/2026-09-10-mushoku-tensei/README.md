# スマスロ「L無職転生～異世界行ったら本気だす～」設定判別ツール

ニューギン「スマスロ L無職転生～異世界行ったら本気だす～」（2025/12/22導入）の設定判別ファンメイド計算機です。

主な参考データは DMMぱちタウンの機種ページ
（[L無職転生～異世界行ったら本気だす～（スマスロ）｜DMMぱちタウン](https://p-town.dmm.com/machines/4924#anc-point)、最終更新日：2026/09/09、機種ID: 4924）の「設定判別・推測ポイント」。
AT初当たり確率・ボーナス確率などDMM側にトータル確率の表が無い項目は、一撃（1geki.jp）の
「[【無職転生（スマスロ/スロット）】設定差・設定判別要素まとめ](https://1geki.jp/slot/l_musyokutensei/0/)」（最終更新日：2026年03月05日）で補完しました。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-mushoku-tensei/

## 機能

- 数値データ入力（① カード）
  - AT初当たり・ボーナス・上位CZ（ターニングポイント2）当選 — 総G数ベースの3チャンネルを共通の総G数で計算
  - 本気ボーナス当選率（ボーナス当選時の振り分け）
  - 無職チャンス成功率（ロキシー・エリス／非対応ヒロイン役）
  - 無職チャンス成功率（シルフィ／非対応ヒロイン役）
  - シーローン王国移行率（ヒトガミの空間以外へのステージ移行時）
- 判別要素チップ（② カード） — 6カテゴリ・36項目をタップでカウント
  - ボーナス・AT終了画面（6項目）
  - 無職チャンス中のゾロ目%表示（3項目）
  - ラウンド開始画面（赤背景）（4項目）
  - 獲得枚数表示（7項目）
  - エンディング（ヒロイン役成立時の出現キャラ）（11項目）
  - 魔術ボーナス中のストーリー紹介（背景色）（5項目）
- 独立二項対数尤度チャンネル＋濃厚/否定によるハード除外＋示唆演出の弱め加重をsoftmaxで統合し、設定1〜6の期待度を③カードに表示
- 数値項目は空欄＝「データなし」として扱い、そのチャンネルの尤度計算をスキップ（0件と誤解釈しない）

## 1geki.jpとのクロスチェック

- CZ成功期待度（ロキシー・エリス／シルフィ）、上位CZ当選率、ゾロ目%表示、獲得枚数表示、ボーナス・AT終了画面、エンディングのキャラ示唆、魔術ボーナスのストーリー紹介 — DMM・1geki両サイトで数値・示唆内容が一致（表記の言い回しのみ差異あり。例: エンディングの「ロキシー（青）」はDMMが「設定2以上濃厚」、1geki が「設定1否定」と表記するが、除外後の候補集合はどちらも{2,3,4,5,6}で完全一致するため`type:'deny', settings:[1]`で統一）
- AT初当たり確率・ボーナス確率 — DMM側には各設定のトータル確率表が掲載されておらず、1geki.jpのみに1〜6の完全な値があったため1geki.jpの数値を採用
- シーローン王国移行率・ヒトガミの空間移行確率 — 両サイトとも同一の表（DMMの「非ヒトガミの空間移行時のステージ振り分け」＝1gekiの「ヒトガミの空間以外のステージ振り分け」）で数値が完全一致

## データについて

以下は発見したが、判別要素として採用しなかったデータです。

- **CZ中の予見眼発生率**（設定1: 17.6% 〜 設定6: 18.7%）: 最大設定差が約1.06倍と小さく、ノイズになりやすいため除外
- **ヒトガミの空間移行確率**（設定1: 1/157 〜 設定6: 1/153）: 差が約2.6%とごく小さいため除外
- **連続演出発生率（ステージチェンジ確率）**（設定1: 1/53.39 〜 設定6: 1/51.70）: 差が約3.2%とごく小さいため除外
- **CZトータル確率**（設定1: 1/130 〜 設定6: 1/125）: 差が約4%とごく小さいため除外
- **CZ中の対応ヒロイン役（シングル/ダブル）当選率**: 設定間でほぼ横ばい（例: 対応シングルは全設定で約50.4%）のため、変化の大きい「非対応シングル」のみ採用し除外
- **ギンちゃんトロフィー**（1geki.jp掲載）: サイト側が「※上記示唆内容は他機種の示唆を参考にした推察」と明記しており、実機で確認された確定情報ではないため除外
- **Vストック関連の各種当選率・振り分け**（ロキシーV/シルフィV/エリスVの特殊効果など）: 出目・ヒロインリンク状況に依存する変数が多く、設定差データとしては掲載されていないため除外

## 技術メモ

`apps/2026-09-06-tokyo-ghoul-slot-checker/` を土台に、共通の白×黒×赤テーマ（CSS変数一式）・HTML骨格（①数値データ／②判別要素／③結果のカード構成、広告スロット、フィードバックウィジェット）・JS設計（`logBinomLikelihood`による独立二項対数尤度チャンネル、`computeCandidateSettings`によるハード除外、`buildChips`によるチップ生成、softmax正規化の`render`）をそのまま流用しています。

空欄フィールドの安全な扱い（`parseField`が空欄を`null`として返し、各チャンネルは自分自身のn/kフィールドが`null`でないときのみ尤度計算に参加する）は `apps/2026-09-07-monhun-rise/` のパターンを採用しました。これにより、共通の総G数チャンネル（AT初当たり／ボーナス／上位CZ）のうち一部だけ数値を入力した場合でも、未入力のチャンネルが「0件観測」と誤解釈されることを防いでいます。
