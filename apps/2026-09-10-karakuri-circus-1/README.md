# スマスロ からくりサーカス（初代）設定判別ツール

「パチスロ からくりサーカス」（2023年07月03日導入・SANKYO製スマスロ、DMMぱちタウン機種ID **4360**）の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4360#anc-point)（2026/08/26更新）と[一撃「からくりサーカス」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_karakuri/0/)（2026/03/05更新）に掲載されている判別要素・数値データから設定期待度を算出します。

**⚠️ 後継機「からくりサーカス2」との違いについて**: 本サイトには2026年07月06日導入の後継機「Lパチスロ からくりサーカス2」（DMMぱちタウン機種ID **5019**）用のツールが[apps/2026-09-06-karakuri-circus-2/](../2026-09-06-karakuri-circus-2/)に別途存在します。本ツールはそれより3年早く導入された**初代機（機種ID 4360）専用**であり、数値データ・判別要素とも完全に別物です。DMMぱちタウンのページ内「シリーズ機種」欄でも初代（導入日2023/07/03）と2（導入日2026/07/06）が別ページとして明確に分かれていることを確認済みです。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-karakuri-circus-1/

## 機能

- **数値データ**（①）: CZ初当り確率（機械仕掛けの神／幕間チャンス合算）とAT初当り確率の2系統を、それぞれ独立した`field-group-label`の見出し付きで入力可能（総G数を共有するため見出しは分離、`totalG`の入力欄は1つで両チャンネルから参照）
- **判別要素**（②）: AT終了画面、踊れ！オリンピア中の連打上乗せ枚数表示、AT開始時のステージ、エンディング中のレア役成立時ランプ色（弱チェリー・スイカ契機／強チェリー・チャンス目契機で分離）を、DMM・一撃の分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 金文字表示の「〜濃厚」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と強さに応じて参考程度の重みだけを加える
- タップ式のカウンターUI（コンパクトな一覧チップ表示でページを短く保つ）
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用
- 空欄の数値入力欄は「未観測（データなし）」として扱い、「0回観測」と誤解釈しないブランク安全設計（`parseField`ヘルパーで`null`と`0`を区別し、各チャンネルは自分のフィールドが非nullの場合のみ計算に使用）

## データについて

- **この機種は設定3のデータが両ソースとも一貫して公表されていない5段階設定として扱う**: DMMぱちタウン・一撃のいずれの数値テーブルも設定1・2・4・5・6の5列のみで構成されており、設定3の列が存在しない（例: 「CZ確率合算」表は両サイトで完全に同一の1/333・1/320・1/292・1/277・1/275という5点データ）。2つの独立ソースで一致してこのパターンが確認されたため、[apps/2026-09-06-valvrave-2/](../2026-09-06-valvrave-2/)と同じ`SETTINGS = [1, 2, 4, 5, 6]`パターンを採用し、設定3を候補から除外した状態で計算する
- 「高設定」と表記されている示唆は設定4以上として扱っている
- 「奇数かつ高設定示唆」「偶数かつ高設定示唆」は該当する設定同士の積集合（例: 敵幹部＝奇数{1,5}∩高設定{4,5,6}={5}のみ、ヒロイン5人＝偶数{2,4,6}∩高設定{4,5,6}={4,6}）として重みを設定
- エンディング中のレア役ランプ色は、弱チェリー・スイカ契機と強チェリー・チャンス目契機で出現率テーブルが異なる（DMMいわく「強レア役の方が示唆内容が若干強くなる」）ため、東京喰種の通常滞在時／高確滞在時の分離と同じ要領で2つの独立したカテゴリに分けて記録する（色の意味自体は共通だが、tier重みを弱チェリー契機=weak、強チェリー契機=normalとして区別）

### 見つけたが数値チャンネル化・チップ化しなかったもの（理由付き）

- **通常時の幕間チャンス出現率（からくりレア役契機）**: 設定1（約1/3000）と設定6（約1/1000）の2点のみ公表され、設定2・4・5のデータが両ソースとも欠落しているため、5段階のうち3段階が不明で補間の根拠がなく見送った
- **エンディング中レア役ランプ色の「赤」**: DMMの表には設定が上がるほど出現率が上昇する数値（弱チェリー契機: 1%→3%→3%→3%→3%、強チェリー契機: 1%→5%→5%→5%→5%）が記載されているが、色の意味を説明する凡例（白=デフォルト／青=奇数示唆／黄=偶数示唆／緑=高設定期待度アップ／紫=4以上濃厚／虹=6濃厚）に「赤」の項目が存在せず、示唆内容が未確定のため採用を見送った（純粋な推測でチップ化することを避けた）
- **AT中のステージのテーブル選択率（テーブル1〜4）**: 4択のカテゴリカル分布であり、単一の二項分布に落とし込むには恣意的にどれか1つを「成功」に選ぶ必要があり、多項分布を複数の独立二項分布として扱うと尤度を過大評価してしまう。「AT開始時のステージ」チップで奇数/偶数示唆は既にカバーされているため見送り
- **DMM記載の「勝ステージ→勝ステージ」「鳴海ステージ→鳴海ステージ」（激情ジャッジ成功を契機とした同一ステージ継続）**: 「偶数かつ設定示唆」「奇数かつ設定示唆」という表記だが、テーブル選択率表から厳密にどのテーブルを指すか一意に確定できず、また「AT開始時のステージ」チップと同じ奇数/偶数示唆情報を重複してカウントしてしまうリスクがあるため採用を見送った
- **踊れ！オリンピア以外の踊れ！オリンピア関連上乗せ振り分け、激情ジャッジ勝率、運命の一劇成功率など**: DMM解析情報の多くの節に数値は存在するが、設定差の記載がない（「基本的に全設定共通」）ため対象外
- 小役確率、CZ・特化ゾーンの各種成功期待度は基本的に全設定共通と明記されているため対象外

判別要素チップ（②のITEMS配列）についてもDMM・一撃の両ページを設定判別・推測ポイントの節を中心に全項目照合し、両ソースで意味が一致することを確認した。

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算・チップUI・CSS・フィードバックウィジェットの実装パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲
- 設定3が存在しない5段階設定のUI・`SETTINGS`配列パターンは[革命機ヴァルヴレイヴ2 設定判別ツール](../2026-09-06-valvrave-2/)を踏襲
- ブランク安全な数値入力パース（`parseField`で空欄と0を区別し、チャンネルごとに自身のフィールドが非nullの場合のみ計算に使用）は[モンハンライズ 設定判別ツール](../2026-09-07-monhun-rise/)の`render()`実装を踏襲
