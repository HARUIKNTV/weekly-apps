# からくりサーカス2 設定判別ツール

「Lパチスロ からくりサーカス2（スマスロ）」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/5019#anc-point)（2026/09/06更新）に掲載されている判別要素をそのままの分類（AT関連／激情ジャッジ／終了画面系／エンディング／獲得枚数表示）で反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-06-karakuri-circus-2/

## 機能

- **数値データ**（①）: CZ合算確率（機械仕掛けの女神／幕間チャンス／劇場ジャッジ）、AT初当たり確率、強チェリー契機のCZ以上当選率、AT開始時のステージ振り分け（勝/鳴海）の4系統を、それぞれ独立した`field-group-label`の見出し付きで区別し、独立した二項尤度チャンネルとして入力可能（CZとAT初当たりは総G数を共有するが、混同を防ぐため見出しは分離）
- **判別要素**（②）: AT開始ステージ、連打時の獲得枚数表示、激情ジャッジのシナリオ、AT終了画面＋ボイス、エンディングのレア役ランプ、獲得枚数表示のすべての要素を、DMMぱちタウンの分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 金文字表示の「〜濃厚」「〜否定」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と強さに応じて参考程度の重みだけを加える
- タップ式のカウンターUI（コンパクトな一覧チップ表示でページを短く保つ）
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用

## データについて

- 「高設定」と表記されている示唆は設定4以上として扱っている
- 「偶数かつ高設定示唆」「奇数かつ高設定示唆」は該当する設定同士の積集合（例: 偶数かつ高設定 → 設定4・6）として重みを設定
- 特定の獲得枚数表示は、DMM記載の出現率データ上も該当設定以外は出現率0%（「一」）だったため、濃厚要素としてハード除外に分類した

## 一撃（1geki.jp）とのクロスチェック（2026-09-07）

[一撃「からくりサーカス2」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_karakuri2/0/)（2026/07/18更新）を確認し、DMM記載のCZ出現率・判別要素はすべて一致することを確認。さらに一撃独自の**AT初当たり確率**（設定1: 1/519 〜 設定6: 1/410）という新しい数値テーブルが見つかったため、数値データ①に追加した。
「CZ終了画面（要PUSH）」のイラスト示唆や「AT終了画面でのボイス」は、モード・AT復活・運命盤関連の示唆であり設定に関するものではなかったため未採用。

## 数値データの細分化（2026-09-08）

[東京喰種の設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)で行った「数値データの細分化」パスと同じ観点で、DMMぱちタウンの機種ページ（設定判別・推測ポイントの節だけでなく、小役確率・CZ・AT・演出情報など全節）と一撃のページを改めて全文確認した。

**構造面の修正**:
- 「CZ確率（機械仕掛けの女神）／AT初当たり確率」という1つの`field-group-label`にCZとAT初当たりという別種の確率がまとめられていたため、東京喰種の裏AT3チャンネル分離と同じ要領で**独立した見出し2つ**（「CZ合算確率」「AT初当たり確率（総G数は上と共通）」）に分離した。総G数の入力欄は共通のため重複させず、既存の`totalG`をそのまま両チャンネルで参照する形にした（東京喰種の「下段リプレイ・AT直撃（総G数は上と共通）」と同じパターン）。
- 合わせて、DMMのページ構成と一撃の「CZ出現率（合算値）」という表記を確認したところ、この数値は「機械仕掛けの女神」単体の確率ではなく**機械仕掛けの女神／幕間チャンス／劇場ジャッジの3種のCZの合算値**であることが判明したため、見出し・入力ラベル・コード内コメントを「CZ合算確率」に訂正した（計算式・数値自体に変更はない）。

**新規チャンネルの追加について**: DMMの全節を再確認したが、追加で採用できる**新しい完結した数値テーブルは見つからなかった**。見つかった候補とその判断は以下の通り。

- 見つけたが**あえて数値チャンネル化しなかったもの**（いずれも設定1〜6で欠損のない完全なテーブルだが、複数カテゴリに分岐する演出であり、かつ既に②の判別要素チップで完全にカバー済みのため、二項尤度チャンネルとして並行追加すると同じ1回の観測を二重に評価してしまう）:
  - 「踊れ！オリンピア」連打時の獲得枚数振り分け（＋20／＋4／＋6、設定1は全て「一」＝0%）— 既存の濃厚チップ（＋20=2以上濃厚など）が0%の設定を完全にハード除外しており、数値チャンネルを足すと同じ表示を2回加点することになるため見送り
  - 特定の獲得枚数表示（222/246/456/666 OVER）— 同上の理由で見送り（既存のハード濃厚チップのみ）
  - 激情ジャッジ：キャラシナリオ振り分け（シナリオ1〜4、設定ごとの選択率）— 4択のカテゴリカル分布であり、単一の二項分布に落とし込むには恣意的にどれか1つを「成功」に選ぶ必要があり、多項分布を複数の独立二項分布として扱うと尤度を過大評価してしまう。既存の示唆チップ（偶数/奇数/高設定示唆）で十分カバーされていると判断し見送り
  - レア役後の点灯色振り分け（白/青/黄/緑/赤/紫/虹 × 弱レア役/強レア役、設定1〜6）— 同上（7色のカテゴリカル分布、既存チップでカバー済み）
- 見つけたが**データ不完全のため見送ったもの**:
  - 強チェリー契機のCZ以上当選率の「高確滞在時」列 — 設定1のみ「約25%」と明記され、設定2〜6は空欄（全設定共通値なのか単に未記載なのか判別できない）。設定別の内訳が確認できないため既存の「通常滞在時」チャンネルのみ採用を継続
- 小役確率、各種CZ・特化ゾーンの成功期待度、当選契機割合などは「基本的に全設定共通」と明記されている、または設定別の内訳が示されていないため対象外

判別要素チップ（②のITEMS配列）についてもDMM・一撃の両ページを全項目照合したが、未収録の濃厚/否定/示唆要素は見つからなかった（既存のチップ一覧がすでに両ソースの設定関連演出を網羅している）。

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算・チップUIの実装パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲
