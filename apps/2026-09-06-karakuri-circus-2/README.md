# からくりサーカス2 設定判別ツール

「Lパチスロ からくりサーカス2（スマスロ）」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/5019#anc-point)（2026/09/06更新）に掲載されている判別要素をそのままの分類（AT関連／激情ジャッジ／終了画面系／エンディング／獲得枚数表示）で反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-06-karakuri-circus-2/

## 機能

- **数値データ**（①）: CZ確率（機械仕掛けの女神）、強チェリー契機のCZ以上当選率、AT開始時のステージ振り分け（勝/鳴海）の3系統をそれぞれ独立した二項尤度チャンネルとして入力可能
- **判別要素**（②）: AT開始ステージ、連打時の獲得枚数表示、激情ジャッジのシナリオ、AT終了画面＋ボイス、エンディングのレア役ランプ、獲得枚数表示のすべての要素を、DMMぱちタウンの分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 金文字表示の「〜濃厚」「〜否定」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と強さに応じて参考程度の重みだけを加える
- タップ式のカウンターUI（コンパクトな一覧チップ表示でページを短く保つ）
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用

## データについて

- 「高設定」と表記されている示唆は設定4以上として扱っている
- 「偶数かつ高設定示唆」「奇数かつ高設定示唆」は該当する設定同士の積集合（例: 偶数かつ高設定 → 設定4・6）として重みを設定
- 特定の獲得枚数表示は、DMM記載の出現率データ上も該当設定以外は出現率0%（「一」）だったため、濃厚要素としてハード除外に分類した

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算・チップUIの実装パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲
