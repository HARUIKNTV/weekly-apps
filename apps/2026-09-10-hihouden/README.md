# スマスロ「秘宝伝」設定判別ツール

パオン・ディーピー「L／スマスロ秘宝伝／PA7」（大都技研シリーズ、2025年12月22日導入）の設定判別を、
プレイヤーが入力した実戦データから算出するファンメイド計算機です。

数値データは [DMMぱちタウン「スマスロ 秘宝伝」設定判別・推測ポイント](https://p-town.dmm.com/machines/4929#anc-point)
（最終更新日：2026/08/27）を主な出典とし、[一撃「秘宝伝（スマスロ）」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_hihouden/0/)
（最終更新日：2026年07月08日）で全数値の一致をクロスチェックしています。

※同時期にDMMぱちタウン等へ掲載されている「クレアの秘宝伝 〜はじまりの扉と太陽の石〜」は本機とは別の機種（旧筐体シリーズ）のため、
本ツールの対象には含んでいません。対象は導入開始日2025/12/22の「スマスロ 秘宝伝」（型式名: L／スマスロ秘宝伝／PA7）です。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-hihouden/

## 機能

- **① 数値データ**: 総G数ベースの確率（ボーナス初当たり・チェリー・謎高確率・140系演出）、チャンス目契機の高確率当選率、
  高確率当選時のBB高確率振り分け、ボーナス中のハズレ確率、伝説モード移行率（「高確率」失敗時／RB後／BB後）の
  合計7つのField-group（17項目）を、二項対数尤度で各設定の尤度に反映します。
- **② 判別要素**: コパンダトロフィー、秘宝伝ニュース（液晶下部）、獲得枚数表示、RB中のキャラ紹介カードの
  4カテゴリ・計19個の示唆演出をタップカウンター形式で記録。金文字の「濃厚/否定」はハード除外（候補の確定・除外）、
  斜体の「示唆」（ファラオ仮面1号・2号）はソフトウェイトのみを加算します。
- **③ 結果**: 6設定それぞれの相対期待度をバー表示。矛盾する濃厚/否定が入力された場合は警告を表示します。
- 全ページ共通のフィードバックウィジェット（右下💬ボタン）を搭載。

## 1geki.jpとのクロスチェックについて

DMMぱちタウンと一撃の両サイトで、以下の数値がすべて一致していることを確認しました（本ツールで採用した全チャンネル）。

- ボーナス初当たり確率（設定1〜6）
- 通常時のチェリー確率（高確率中を除く）
- リプレイ契機の高確率（謎高確率）当選確率
- 140系演出（秘宝伝ニュース「1時40分」＋獲得枚数「140OVER」）のトータル出現確率
- チャンス目契機の「高確率」当選期待度（非伝説モード中）
- 「高確率」当選時の「BB高確率」振り分け（非伝説モード中）
- ボーナス中のハズレ確率
- 「高確率」失敗時の伝説モード移行率
- ボーナス当選時の伝説モード移行率（RB後・BB後）
- コパンダトロフィー／秘宝伝ニュース／獲得枚数表示／RB中のキャラ紹介カードの示唆内容

一撃側にのみ掲載されていた「ボーナス初当たり確率」の完全な6設定分の表は、DMM側の本文中の言及（初当たりの偶奇差についての記述）と
矛盾がないことを確認した上で採用しています。

## データについて

以下は発見したものの、理由があって今回は採用を見送ったデータです。

- **RB後・3の倍数連目のボーナス当選時の伝説モード移行率**（設定1〜6: 50.0%, 55.2%, 52.9%, 56.0%, 54.9%, 57.3%）:
  両サイトとも数値自体は6設定分そろっていますが、「3連目・6連目…」というボーナス連チャン回数の倍数位置を
  プレイ中に正確に見分けて別カウントするのはハードルが高く、通常のRB当選（3の倍数連目以外）チャンネルと
  概念が重複するため、実装の複雑さに見合わないと判断し見送りました。
- **ダブルBIG当選時の伝説モード移行率／3の倍数連目のダブルBIG当選時の伝説モード移行率**:
  DMMぱちタウンの表では設定1（100%）以外の値が空欄で、5設定分のデータが欠落しているため不採用（不完全データ）。
- **高確率当選時のBB高確率振り分け（伝説モード中）**（設定1〜6: 5.1%, 5.5%, 5.9%, 6.6%, 7.8%, 8.6%）:
  非伝説モード中のバージョンのみ採用しました。両サイトとも「見た目は通常時とほぼ同じで、伝説モードに滞在しているか
  完全に見抜くのは難しい」と明記されており、プレイヤー自身が伝説モード滞在を確実に判定して分母を数えるのは
  現実的でないため見送りました。
- **秘宝伝ニュース「1時40分」／獲得枚数表示「140OVER」単体の示唆演出カウント**:
  ①の数値データで「140系演出出現回数」としてDMM公表のトータル出現確率（両演出の合算値）を使って集計しているため、
  ②の判別要素チップとして同じ演出を再度カウントすると証拠を二重計上してしまいます。そのため②からは意図的に除外しています。
- **伝説モード滞在を示唆する各種演出**（壁画演出「天の神（座り）」、インターフェース変化（満月/赤月/否）、
  見守りクレア演出、アイキャッチ演出の砂金/ベロベロ大魔神、特殊フラッシュ、壁押し演出、初代系演出など）:
  いずれも「伝説モードに滞在しているか」を示唆するものであり、特定の設定値を示唆するものではないため、
  本ツールの設定推測モデル（設定1〜6のsoftmax）には組み込めず不採用としました。
- **ボーナス終了画面PUSHの「ベカン子との遭遇」演出**、**RB中のキャラ紹介カードの「ベロベロ大魔神」**:
  いずれも「設定変更濃厚」を示唆するものであり、特定の設定値ではなく「設定が変更されたこと」自体を示す演出のため、
  設定1〜6の相対尤度モデルには反映できず不採用としました。

## 技術メモ

- HTML構造・CSS（白／黒／赤のパレット）・広告スロット・フィードバックウィジェットは
  [`apps/2026-09-06-tokyo-ghoul-slot-checker/`](../2026-09-06-tokyo-ghoul-slot-checker/) を踏襲しています。
- 空欄フィールドの安全な扱い（「未入力」と「0回」を区別するnull判定）は
  [`apps/2026-09-07-monhun-rise/`](../2026-09-07-monhun-rise/) の `parseField` パターンを踏襲し、
  本ツールでは①のすべてのチャンネル（総G数を共有する5項目も含む）に一律で適用しています。
- 6設定すべてが存在する機種のため、`SETTINGS` 配列パターン（5設定機種向け）は使用せず、標準の
  `[1, 2, 3, 4, 5, 6]` 配列で計算しています。
- 各設定の対数尤度は二項対数尤度（`logBinomLikelihood`）の合算＋示唆演出のソフトウェイト加算で構成し、
  softmax正規化して確率バーとして表示しています。
