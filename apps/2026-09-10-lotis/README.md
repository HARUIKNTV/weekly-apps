# ローティス 設定判別ツール

沖スロ「ローティス」（北電子、型式名：LローティスTN、2026年7月6日導入）の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/5029#anc-point)（2026/08/29更新）と[一撃「ローティス」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_lotis/0/)（2026/07/19更新）に掲載されている数値データ・示唆演出をもとに、実戦データと出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-lotis/

## この機種の特徴：設定3が存在しない

DMMぱちタウン・一撃のいずれの設定差テーブルも設定1・2・4・5・6の5列のみで構成されており、設定3が存在しない5段階設定の機種。本ツールも`SETTINGS = [1, 2, 4, 5, 6]`という設定空間で計算しており、結果表示にも設定3は出てこない。

## 機能

- **数値データ**（①）: 以下5つを独立した二項尤度チャンネルとして入力可能
  - BB初当たり確率・RB初当たり確率（一撃、総G数を共有）
  - リアルチェリー合算確率（DMM、総G数を共有）
  - 前兆移行率（本前兆＆フェイク前兆合算トータル、総G数を共有）
  - フェイク前兆中の本前兆書き換え当選率（全契機トータル合算、フェイク前兆回数を分母とする独立チャンネル）
- **判別要素**（②）: ボーナス終了時の下パネル点滅・下パネル高速点滅をタップ式カウンターで記録。いずれも金文字の「〜濃厚」表記の確定情報で、1回でも出現すれば矛盾する設定を候補から除外
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用

## 一撃（1geki.jp）とのクロスチェック（2026-09-10）

DMMぱちタウンの「設定判別・推測ポイント」には「小役確率」（リアルチェリー確率・合算確率）と「ボーナス終了時」（下パネル点滅発生率）のみが掲載されており、ボーナス初当たり確率はBB/RBの内訳が示されていなかった。一撃の設定差ページを確認したところ、以下が新たに見つかったため採用した。

- **BB初当たり確率・RB初当たり確率**（設定1: BB 1/677.7・RB 1/514.1 〜 設定6: BB 1/627.1・RB 1/457.4）— DMMの「ボーナス合算確率」（右記以外）はBB・RB合算値のみだったが、一撃はBB/RBを分けて公開していたため、より情報量の多い分割版を採用し、合算値の重複計上を避けた
- **前兆移行率（本前兆＆フェイク前兆合算トータル）**（設定1: 1/163.2 〜 設定6: 1/148.2）— DMMにも同内容の記載があったが、一撃の表記の方が整理されていたためこちらの数値で統一
- **フェイク前兆中の本前兆書き換え当選率（全契機トータル合算）**（設定1: 約26.2% 〜 設定6: 約29.7%）— DMM・一撃どちらにも掲載されていたが、独立した試行（フェイク前兆回数を分母とする）として扱えるため別チャンネルとして追加

どちらのサイトも設定3の行が存在せず、5段階設定であることが相互に確認できた。

## データについて

以下は公開データを確認したが、採用しなかった要素とその理由。

- **擬似チェリー確率・小役確率（スイカ・中段チェリー）の個別設定別テーブル**: DMMの表は設定1のみ数値が入り、設定2・4・5・6の欄が空欄（「一」表記もなく単純に未掲載）だったため、設定間の差が確認できず未採用
- **リアルチェリーの斜め揃い／平行揃いの内訳**: DMMのテーブルは斜め揃いが設定1のみ、平行揃いが設定2・4・5・6のみと、列ごとに掲載されている設定が食い違っており、正確な対応関係が確認できなかったため、代わりに全設定で数値が揃っている「リアルチェリーの合算確率」を採用した
- **下パネル高速点滅の発生率（一撃の実測値）**: 一撃では設定2: 約1/32.0、設定6: 約1/19.7のみ数値があり、設定4・5は「???」「空欄」と明記されていたため、発生率としての数値チャンネル化はせず、②のチップでは「発生した／しなかった」の有無のみを確定情報として扱った
- **モード関連の示唆演出**（ナビランプの色、ボーナス告知パターン、蓮の花ランプ点灯パターン、サンセットランプ点灯、中段チェリーのSBB濃厚など）: いずれも「天国以上濃厚」「SBB濃厚」「極楽以上濃厚」など内部モード・ストックを示唆するものであり、設定そのものを示唆する要素ではないため未採用
- **SBBストック当選率（設定変更時）**: 設定変更（リセット）直後にのみ意味を持つ抽選であり、プレイヤーが自力でリセット判定した上でしか使えない特殊な条件付きデータのため、通常の実戦データとして扱いにくく未採用
- **ハラキリチャレンジ相当の技術介入示唆**: 本機の技術介入（赤7/紫7）はSBBストック数・滞在モードの示唆であり、設定示唆ではないため未採用

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 設定空間を`SETTINGS`配列で保持し、確率テーブルもオブジェクト（`{1: ..., 2: ..., 4: ..., 5: ..., 6: ...}`）で持たせることで、設定3が存在しない5段階設定の機種に対応した（[革命機ヴァルヴレイヴ2版](../2026-09-06-valvrave-2/)と同じ方針）
- 空欄の入力欄を「未入力」と「0」で区別する`parseField`（[モンハンライズ版](../2026-09-07-monhun-rise/)より踏襲）により、同じ総G数を共有するチャンネルの一部だけ未記入でも誤って「0回」として計算されないようにした
- チップUI・尤度計算の基本パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲
