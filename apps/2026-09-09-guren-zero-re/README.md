# スマスロ「喰霊-零-Re」設定判別ツール

オーイズミ「Lパチスロ 喰霊-零-Re」（A+ARTタイプ・2026年8月17日導入）の設定判別ファンメイド計算機です。数値データ（スイカ・弱チェリー確率、BIG/REG確率、チェリー契機の超自然災害モード当選率）と、示唆演出の出現回数（タップカウンター）を組み合わせ、二項分布の対数尤度＋softmaxで設定1〜6の期待度を算出します。

参考データ:
- [DMMぱちタウン「Lパチスロ 喰霊-零-Re」設定判別・推測ポイント](https://p-town.dmm.com/machines/5028#anc-point)（2026/09/09更新時点で取得）
- [一撃「喰霊零Re（スマスロ）」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_garei0_re/0/)（2026/08/17更新）

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-09-guren-zero-re/

## 機能

- **数値データ入力（①）**
  - 小役・ボーナス確率（総G数ベース）: 総G数に対するスイカ・弱チェリー・BIG・REGの各成立回数
  - 弱チェリー契機の超自然災害モード当選率（通常時）: 通常時の弱チェリー成立回数とCZ当選回数
  - 強チェリー契機の超自然災害モード当選率（通常時）: 通常時の強チェリー成立回数とCZ当選回数
  - 各項目は空欄なら「データなし」として扱われ、その項目だけが計算から除外されます（0回だったと誤って解釈することはありません）。
- **判別要素タップカウンター（②）**
  - ボーナス終了画面／ART終了画面／獲得枚数表示: 「〜以上濃厚」「〜濃厚」の確定演出（ハード除外）
  - 特定役ボーナス: スイカ・強チェリー絡みのボーナス種別による「奇数/偶数設定優遇」「高設定示唆」（参考程度のソフト加点）
- **結果表示（③）**: 設定1〜6ごとの期待度をバーで表示し、濃厚演出と矛盾する設定は自動的に候補から除外されます。

### 1geki.jpとのクロスチェックについて

DMMぱちタウンと一撃（1geki.jp）の両サイトを全文確認し、スイカ・弱チェリー確率、チェリー契機の超自然災害モード当選率、終了画面・獲得枚数表示による示唆演出はいずれも同じ数値・内容で一致していることを確認しました。BIG/REG（ボーナス）当選確率の設定1〜6完全テーブルは一撃側にのみ掲載されていたため、そちらを採用しています。

## データについて

以下は原文に記載はあったものの、今回の数値チャンネル・判別要素としては**採用しませんでした**（理由付き）。

- **ART初当り確率**: 設定1（1/468.6）のみ判明、設定2〜6は「???」。設定差のある完全な表ではないため見送り。
- **CZ「超自然災害モード」当選確率**: 設定1（1/287.2）のみ判明、他設定は未判明のため見送り。
- **CZ「解放の刻」当選確率**: 1/1200.0で「全設定共通」と明記されており、設定差そのものが存在しないため見送り。
- **超自然災害モード・乱撃の突入率**: 設定1（1.56%）のみ判明、設定2〜6は「???」のため見送り。
- **3枚ベル・共通ベル・リプレイ・強チェリー・弱チャンス目・強チャンス目・リーチ目リプレイの確率**: DMMぱちタウンでは設定1のみ数値があり、設定2〜6はすべて「調査中」。完全な表ではないため見送り（スイカ・弱チェリーのみ設定1〜6が判明していたため採用）。
- **殺生石チャレンジ当選率**: 「通常中／高確中／超高確中」という内部状態別の表であり、設定別の表ではないため見送り。
- **ステージ示唆（公園＝高確or前兆示唆、幼少期＝超高確示唆）**: 設定ではなく内部状態（モード）を示唆する演出のため見送り（指示に基づき除外）。
- **REG中のキャラ紹介の設定示唆**: 「設定示唆パターンあり」とのみ記載され、具体的な示唆内容・設定対応が不明なため見送り。
- **継続バトルのキャラ別期待度・連続演出期待度（魍魎/火車など）**: ART継続率・演出のジャッジ精度に関する期待度であり、設定判別要素ではないため見送り。
- **踏切（ART終了画面）**: 「エンディング後専用」の表示であり、設定示唆ではないため判別要素から除外。
- **携帯電話／対策室（各終了画面のデフォルト）**: 無地の「デフォルト」表示であり示唆なしのため除外。

このように、判明している設定差データが薄い機種（新台まもなく解析途上）のため、数値チャンネルは6件（総G数ベース4件＋チェリー契機CZ当選率2件）にとどめています。今後の情報更新（特にART初当り確率・CZ当選確率・小役確率の続報）に応じて追加できます。

## 技術メモ

`apps/2026-09-06-tokyo-ghoul-slot-checker/` を参照実装として、CSS（白／黒／赤の配色、`.field-group-label` / `.chip` / `.result-bars` 等）とJS構成（`logBinomLikelihood` による二項対数尤度、`buildChips` によるチップ生成、`computeCandidateSettings` によるハード除外、`render` でのsoftmax正規化）をそのまま踏襲しています。

空欄フィールドの扱いについては `apps/2026-09-07-monhun-rise/` の `parseField` パターン（空欄は `null` として扱い、そのチャンネルだけを計算から除外する）を採用し、「総G数は入力済みだが一部のk値だけ空欄」というケースでも、空欄の項目を「0回だった」と誤って解釈しないようにしています。
