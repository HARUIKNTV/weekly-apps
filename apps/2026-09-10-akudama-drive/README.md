# スマスロ「Lアクダマドライブ」設定判別ツール

サンスリー『Lアクダマドライブ』（2026年4月6日導入開始）の設定判別ファンメイド計算機です。
[DMMぱちタウン「Lアクダマドライブ」設定判別・推測ポイント](https://p-town.dmm.com/machines/4956)（2026/09/01更新）を主データソースとし、
[一撃「アクダマドライブ（スロット）」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_akudama_drive/0/)（2026/04/20更新）とクロスチェックした上で構築しています。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-10-akudama-drive/

## 機能

- **① 数値データ**：プレイした実戦値（総G数・当選回数など）を入力すると、設定1〜6ごとの二項対数尤度を積み上げて相対尤度を計算します。
  - AT初当たり・ボーナス初当たり・CZ出現率（総G数ベース、3チャンネルとも同じ総G数を分母として共有）
  - シンテツドウポイント0到達時のアナライズチャレンジ当選率
  - 多脚戦車バトル敗北後のCZモード昇格率
  - アクダマボーナス当選時のエピソードボーナス昇格率
  - 空欄の項目は「未入力＝データなし」として扱い、そのチャンネルの尤度計算をスキップします（0回成立と誤認しません）。
- **② 判別要素**：出現した示唆演出をタップしてカウント。「濃厚/否定」（金文字）は候補設定をハード除外・確定し、「示唆」（斜体）はソフトマックスに小さな重みを加えるだけに留めています。
  - クジラッキートロフィー（(超)ST・処刑課バトル終了画面）：銅／銀／金／クマノミ柄／虹
  - ST終了画面PUSH時の示唆：偶数／奇数／高設定示唆／画面据え置き（4以上濃厚）
  - ハッカー上乗せ中のG数表示による示唆：+22G〜+6・66G
  - エンディング中のターゲットランプ色（アクダマ目停止時）：青／黄／緑／赤／虹
- **③ 結果**：設定1〜6の相対期待度をバーで表示し、現在の候補設定と最有力設定をまとめます。

## データについて

DMMぱちタウン・一撃の両サイトとも、本機は設定1〜6の完全な数値テーブルが公開されており、欠落設定はありませんでした（サイト方針上、設定が一部でも欠落しているデータは全設定を除外する必要がありますが、今回は該当なし）。

### 発見したが採用を見送った要素（理由）

- **ST終了画面（遊園地／十字架／ロケット／絶対隔離領域）の「次回◯セット以内に処刑課バトル濃厚、否定で設定4以上濃厚」**：出現直後ではなく、規定セット数消化後に発生の有無が確定して初めて設定判別材料になる条件付き示唆のため、単発タップのチップ集計モデルでは正しく表現できず見送りました。
- **ST終了画面「処刑課」表示**：「次回ATは処刑課バトルが近いかも」という弱い示唆にとどまり、設定との明確な対応関係が示されていないため見送りました。
- **エンディング中ターゲットランプ「白」**：両サイトとも「デフォルト（基本パターン）」と明記されており、設定的な意味を持たないため採用しませんでした。
- **処刑課バトル中のキャラ別成功期待度・カットイン色（AT・上位AT中のBAR示唆）**：設定差ではなく「残りゲーム数」「当選契機」に応じた挙動の説明であり、設定判別要素として明記されていないため見送りました。
- **カンサイ教育番組・フェーズ移行抽選などの通常時ゲームフロー数値**：設定差の記載がある一部（悪揃い・チャンス目の移行率など）を除き、多くは全設定共通の抽選値であることが明記されており、設定判別には使えないため除外しました。

## 技術メモ

UI・計算ロジックは [apps/2026-09-06-tokyo-ghoul-slot-checker/](../2026-09-06-tokyo-ghoul-slot-checker/) をベースに、`parseField` による空欄安全性（[apps/2026-09-07-monhun-rise/](../2026-09-07-monhun-rise/) のパターンを採用）を組み合わせて構築しました。

- 独立チャンネルごとの二項対数尤度（`logBinomLikelihood`）を積み上げ、softmax で正規化して設定1〜6の相対期待度を算出。
- 「濃厚/否定」チップは `computeCandidateSettings()` でハード除外・絞り込みを行い、除外された設定はバーを灰色化して「除外」表示。
- 「示唆」チップは tier（弱／通常／強）ごとの小さな重み（`TIER_WEIGHT`）のみを加算し、確定情報として扱わない。
- フィードバックウィジェット（画面右下の💬ボタン）はサイト共通のFormSubmit.co送信フォームをそのまま流用。

※本ツールは公開データに基づくファンメイド計算機であり、実際の設定を保証するものではありません。
