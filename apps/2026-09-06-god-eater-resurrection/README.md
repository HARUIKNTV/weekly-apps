# ゴッドイーター リザレクション 設定判別ツール

「スマスロ ゴッドイーター リザレクション」の設定判別を助ける計算ツール。[DMMぱちタウンの機種ページ「設定判別・推測ポイント」](https://p-town.dmm.com/machines/4602#anc-point)（2026/08/30更新）に掲載されている判別要素をそのままの分類（AT終了画面／ストーリーパート終了時のボイス／枚数決定ゾーン／通常時演出／獲得枚数表示／エンディング）で反映し、実戦データと示唆演出の出現回数から設定期待度を算出します。

公開URL: https://haruikntv.github.io/weekly-apps/2026-09-06-god-eater-resurrection/

## 機能

- **数値データ**（①）: CZ確率（アラガミ防衛戦＋殲滅モード合算）、AT「アラガミバースト」出現率、弱チェリー契機のCZ当選率、スイカ契機のCZ当選率、チャンス目契機のCZ当選率、強チェリー契機のAT直撃当選率——計6系統をそれぞれ独立した`field-group-label`見出し・独立した二項尤度チャンネルとして入力可能（弱チェリー／スイカ／チャンス目は同じ「レア役契機のCZ当選率」という括りでも、実体は3つの別々の確率テーブルのため見出しを分離）
- **判別要素**（②）: AT終了画面、ストーリーパート終了時のボイス、枚数決定ゾーンの連打上乗せ表示、ユウタイマー演出、獲得枚数表示、エンディングのレア役成立時のボイスのすべての要素を、DMMぱちタウンの分類のままカテゴリラベル付きで1つのリストにまとめてタップ式カウンターで記録
  - 金文字表示の「〜濃厚」「〜否定」は1回でも出現すれば矛盾する設定を候補から確実に除外
  - 斜体表示の「〜示唆」は確定情報ではないため、ハード除外はせず出現回数と強さに応じて参考程度の重みだけを加える
- 広告枠を3か所設置（ヘッダー直下728×90、判別要素と結果の間300×250、フッター上728×90）— プレースホルダー表示のみ
- モバイル表示時の日本語の不自然な改行を防ぐCSS（`word-break: keep-all`）を適用

## 一撃（1geki.jp）とのクロスチェック（2026-09-07）

[一撃「ゴッドイーター」設定差・設定判別要素まとめ](https://1geki.jp/slot/l_godeater_r/0/)（2026/01/13更新）を確認し、DMM記載のCZ合算確率・レア役契機のCZ当選率・強チェリー契機のAT直撃当選率はすべて一致することを確認（強チェリー成立時のCZ当選率55.2%が全設定共通という点も含めて一致）。さらに一撃独自の**AT「アラガミバースト」出現率**（設定1: 1/351.9 〜 設定6: 1/290.3）という新しい数値テーブルが見つかったため、数値データ①に追加した。
「ケロットトロフィー」の出現や、レア役全般からのAT直撃当選率・規定ゲーム数当選率の設定差は「〜と思われる」という推測段階の記述にとどまり、具体的な数値や確定要素の説明がなかったため未採用。

## 数値データの細分化（2026-09-08）

[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)で行った「①数値データの細分化」と同じ観点で、DMMぱちタウン「設定判別・推測ポイント」（機種ページ全体、演出情報・解析情報の各セクションも含めて再確認）と一撃のページを改めて全文チェックした。

- 見出し（`field-group-label`）の分割:
  - 「CZ確率（アラガミ防衛戦＋殲滅モード合算）／AT「アラガミバースト」出現率」という1つの見出しに、実体が別々の確率テーブル（CZ確率とAT出現率、それぞれ独立した`P_CZ`・`P_AT`配列）が"／"でまとめられて同居していたため、**「CZ確率（アラガミ防衛戦＋殲滅モード合算）」**と**「AT「アラガミバースト」出現率（総G数は上と共通・一撃調べ）」**の2つの独立した見出しに分割した
  - 「通常時レア役契機のCZ当選率」という1つの見出しの下に、弱チェリー・スイカ・チャンス目という3つの別々の役（それぞれ別のN/Kの入力・別の`P_WEAK_CHERRY_CZ`/`P_SUIKA_CZ`/`P_CHANCE_CZ`配列）が同居していたため、**「弱チェリー契機のCZ当選率（通常時）」「スイカ契機のCZ当選率（通常時）」「チャンス目契機のCZ当選率（通常時）」**の3つの独立した見出しに分割した
  - 入力欄のid・`numericInputs`の並び・`render()`内のロジックはすべて変更前と同一（HTML上の見出し・グルーピングのみを分離）のため、計算結果への影響はない
- 新規追加した数値テーブル: なし。DMMぱちタウンの機種ページ全文（設定判別・推測ポイント／天井・ゾーン・ヤメ時／打ち方朝イチ／解析情報通常時／解析情報ボーナス時／演出情報の全セクション）と一撃のページを再確認したが、設定差のある数値テーブルはCZ確率・AT「アラガミバースト」出現率・レア役契機のCZ当選率（弱チェリー／スイカ／チャンス目）・強チェリー契機のAT直撃当選率のみで、これらはすべて既存（2026-09-07のクロスチェック時点）で採用済みだった
- 判別要素（チップ）についても、AT終了画面／ストーリーパート終了時のボイス／連打上乗せ表示／ユウタイマー演出／獲得枚数表示／エンディングのボイスの各カテゴリを再確認したが、DMM・一撃の両ページに掲載されている要素はすべて既存の`ITEMS`配列でカバー済みで、追加すべき新しい濃厚/否定/示唆要素は見つからなかった
- 引き続き未採用（理由も変更なし）:
  - 強チェリー成立時のCZ当選率（55.2%）: 設定1のみ数値が掲載され、設定2以降は空欄。一撃側も同じ表記で「全設定共通」の位置づけであり、設定差のある独立チャンネルとしては扱えない
  - ケロットトロフィー: 一撃に「実戦上ではあるが...他機種同様の設定示唆要素があると思われる」という推測段階の記述のみで、具体的な示唆内容や濃厚設定の記載がない
  - レア役全般からのAT直撃当選率・規定ゲーム数（200G/450G）当選率の設定差: 一撃に「設定差があると思われる」「高設定ほど当選率が高い!?」という推測の記述のみで、具体的な数値テーブルが掲載されていない

## データについて

- 「リンドウ」「シオ」の一部の示唆（ストーリーパート終了時のボイス／エンディングのボイス）は、DMM記載が「設定n以上」で「濃厚」の表記がなかったため、確定要素ではなく示唆（参考程度）として分類している
- 「ストーリーパート終了時のボイス」と「エンディング：レア役成立時のボイス」はDMM側の説明文で「ボイスの内容は共通」とされているが、発生する場面（ストーリーパート終了時／エンディング中）が異なる別々の出来事のため、それぞれ独立したカウンターとして用意した
- 強チェリー成立時のCZ当選率（55.2%）は設定差がなく全設定共通の値だったため、判別要素としては採用していない

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル（プレーンなHTML/CSS/JS）。ビルド不要で、そのまま静的ホスティング可能
- 尤度計算・チップUIの実装パターンは[スマスロ東京喰種 設定判別ツール](../2026-09-06-tokyo-ghoul-slot-checker/)を参照実装として踏襲
